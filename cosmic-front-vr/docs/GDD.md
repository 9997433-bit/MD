# Cosmic Front VR — 游戏设计文档（核心）

## 1. 核心循环

```
机库选阵营/机甲 → 匹配或单机 → 载入战场 → 对战 → 结算(K/D/分数) → 回机库
```

## 2. 模式（MVP）

### 团队死斗 Team Deathmatch

- 人数：8v8（测试期 4v4）
- 时长：10 分钟 或 先达 50 杀
- 重生：10 秒，出生点 3 秒无敌
- 胜利：击杀分高者胜

## 3. 机甲操作（VR）

| 操作 | 输入 |
|------|------|
| 平移 | 左摇杆（六向：前后左右上下需配合） |
| 机体转向 Yaw | 右摇杆 X |
| 机体俯仰 Pitch | 右摇杆 Y（限制 ±30°） |
| 主武器 | 右扳机 |
| 副武器 | 左扳机 |
| 锁定 | 左 grip / 侧键 |
| 推进冲刺 | 左摇杆按下 |
| 切换武器 | 右 A / X 键 |

### 编辑器测试键位（无头显）

- WASD 平移，QE Yaw，RF Pitch
- 空格冲刺，鼠标左键主武器，右键副武器，Tab 锁定

## 4. 战斗数值（初版）

| 参数 | 轻型 Kestrel | 重型 Bastion |
|------|--------------|--------------|
| HP | 100 | 200 |
| 盾 | 50 | 80 |
| 最大速度 | 18 m/s | 12 m/s |
| 推进剂 | 100 | 70 |
| 主武器 DPS | 30 | 45 |
| 副武器 | 2 发导弹 | 4 发导弹 |

## 5. 锁定系统

- 准星锥形 15° 内可选目标
- 按锁定键锁定最近敌人，再按切换
- 锁定后主武器轻微追踪（非全追踪）

## 6. 地图设计要点

### Station Rim（环带外壁）

- 长 400m 平台，两侧虚空
- 5 处集装箱掩体
- 4 个出生点（两端各 2）

### Debris Lane（碎屑航道）

- 200×200m 区域，10 块大岩石
- 视野破碎，适合轻型机

## 8. 战舰系统（P4）

详见 [SHIP_SYSTEM.md](SHIP_SYSTEM.md)

- 护卫舰 Aegis：舵手 / 炮手 / 舰长 / 弹射
- 机库可选「机甲」或「登舰职位」
- 战斗地图自动生成双方战舰

## 9. AI（P1）

- 状态：Idle → Chase → Attack → Dead
- 攻击距离内停火并侧移
- 被击后 2 秒内增加攻击性
