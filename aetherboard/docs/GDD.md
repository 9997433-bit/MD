# Aetherboard 游戏设计文档（GDD）

> 学习对象：《FF14 重生之境》ARR 时代副本战斗节奏  
> 产品形态：VR 互动战棋（当前阶段：2D 原型验证）

## 1. 核心体验

玩家以 **小队指挥官** 身份，在固定节奏回合中：

1. 读懂 Boss 机制预警
2. 移动棋子规避地板
3. 在 GCD 窗口打出主技能
4. 在 oGCD 窗口插入能力技（减伤、打断、团 buff）

**设计原则**：可读性 > 复杂度；分工明确；失败原因清晰。

## 2. 回合结构

| 阶段 | 时长（VR 目标） | 行为 |
|------|----------------|------|
| 预警 | 2s | 显示机制 telegraph |
| 移动 | 3s | 每单位移动（职业移动力不同） |
| GCD 行动 | 5s | 每单位 1 个 GCD 技能 |
| oGCD 插入 | 2s | 每单位 0~1 个 oGCD |
| 结算 | 自动 | 机制触发 + Boss 普攻 + 状态递减 |

## 3. 职业设计

### 铁卫（Tank）

- **定位**：承伤、仇恨、打断
- **移动力**：1
- **技能**：盾击(GCD) / 铁壁(oGCD) / 挑衅(oGCD) / 打断(oGCD，读条窗）

### 白愈（Healer）

- **定位**：单抬 + 小范围群疗
- **移动力**：1
- **技能**：治疗(GCD) / 医技(GCD AoE) / 天赐(oGCD)

### 黑炎（DPS 读条）

- **定位**：高伤害，怕移动
- **移动力**：1
- **技能**：火炎(GCD，未移动 +50%) / 冰结(GCD) / 魔罩(oGCD)

### 游弦（Support DPS）

- **定位**：稳定输出 + 团 buff
- **移动力**：2
- **技能**：强力射击(GCD) / 魔人歌(oGCD) / 后跃射(oGCD)

## 4. Boss 战

### 土灵守护者（earth）

| 阶段 | HP 阈值 | 机制 |
|------|---------|------|
| P1 | 100%~70% | **重击**：Boss 周围 3×3 范围高伤 |
| P2 | 70%~40% | **地震**：随机 3×3 危险格（预警时锁定位置） |
| P3 | 40%~0% | **缩圈** + **土神之怒**（2 回合读条，未打断即 wipe） |

### 风灵领主（wind）

| 阶段 | HP 阈值 | 机制 |
|------|---------|------|
| P1 | 100%~70% | **风刃**：中央列直线高伤 |
| P2 | 70%~40% | **分散**：相邻友军同时受创 |
| P3 | 40%~0% | **集合** + **旋风**（2 回合读条，可打断） |

### 冰灵女皇（ice）

| 阶段 | HP 阈值 | 机制 |
|------|---------|------|
| P1 | 100%~70% | **冰枪**：Boss 位置十字路径高伤 |
| P2 | 70%~40% | **霜冻**：随机 2×2 危险区（预警时锁定） |
| P3 | 40%~0% | **冰环**（距中心曼哈顿距离=2）+ **暴雪**（2 回合读条，可打断） |

## 5. 棋盘规则

- 7×7 网格，Boss 固定 `(3, 2)`，不可占用
- 单位不可重叠
- 危险格（HAZARD）：机制造成，停留即死（结算时判定）
- 朝向简化：首版不做 flank/rear，后续 VR 版可加

## 6. 数值基线（MVP）

- Boss HP：6000
- 铁卫：1200 HP
- 白愈：900 HP
- 黑炎：800 HP
- 游弦：850 HP
- Boss 普攻：P1 140 / P2 180 / P3 220
- 减伤（铁壁/魔罩）：伤害 ×0.6，持续 2 回合
- 魔人歌：全队 GCD 伤害 ×1.2，持续 3 回合

## 7. VR 交互映射（规划）

| 2D 操作 | VR 操作 |
|---------|---------|
| 点击棋子 | 手柄抓取 |
| 点击格子 | 松手放置（吸附） |
| 技能按钮 | 手腕环 / 指向技能扇形 |
| 读条观察 | 自然抬头看 Boss UI |
| 集合/分散 | 语音或指令盘 |

## 8. 内容扩展路线

1. ✅ MVP：1 Boss + 4 职业 + 阶段机制
2. ✅ 新增 Boss（风元素：分散/集合；冰元素：十字/霜冻/冰环）
3. 8 职业精简版或双职责切换
4. ✅ 本地 2 人协控（一人 2 棋）
5. Unity VR 桌台 + 手势忍术组合
