# 光径 BEAM PATH

浏览器里的激光反射解谜小游戏：转动反射镜，把氦氖红光送进光电探测器。

## 怎么玩

```bash
cd laser_game
python3 -m http.server 8766
```

打开 http://localhost:8766

1. 点击棋盘上的反射镜，每次旋转 90°
2. 点「发射」观察光路
3. 全部探测器点亮即过关（共 6 关）
