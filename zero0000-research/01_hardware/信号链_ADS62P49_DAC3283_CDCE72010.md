# 高速采集/激励板典型信号链:ADS62P49 + DAC3283 + CDCE72010

> 研究目的:为 zero0000 板(BOM 见 `BOM_证据分级.md`)的信号链逆向与阶段 5 实测提供依据。
> 关键佐证:**这三颗芯片 + 491.52 MHz VCXO 的组合与 4DSP/Abaco FMC150 参考设计完全同构**
> (FMC150 = ADS62P49 双通道 ADC + DAC3283 双通道 DAC + CDCE72010 时钟树,外部时钟/参考 + 触发输入)[FMC150]。
> zero0000 板上 X1 = 491.520 MHz 振荡器与 FMC150 的 VCXO 频率一致,进一步支持该架构推断(🔶)。

**证据等级**:✅ 数据手册原文/官方文档;🔶 官方文档 + 板级照片推断;❓ 待实测确认。

## 2. 典型连接:时钟 → ADC/DAC → FPGA

以 FMC150 参考架构为蓝本(与 zero0000 板 BOM 一致,🔶 [FMC150][SCAA092]):

```text
                       ┌────────────────────────────────────────────┐
 CLK_IN (SMA, 外部参考) ──► PRI_REF ┐                                │
 板载 100 MHz OSC ──────► SEC_REF ┤  CDCE72010 (PLL+分频+分配)       │
                       │          │        ▲                        │
                       │   环路滤波器 ◄──┐  │ VCXO_IN                │
                       │               └── X1: 491.52 MHz VCXO      │
                       │  输出分配(SPI 可编程,LVPECL/LVDS):          │
                       │   Y? ──► ADS62P49 CLKP/N   245.76 MHz (/2) │
                       │   Y? ──► DAC3283 DACCLKP/N 491.52 MHz (/1) │
                       │   Y? ──► FPGA 参考时钟(可选)                │
                       └────────────────────────────────────────────┘

 SIG (SMA) ──► 变压器/巴伦 AC 耦合 ──► ADS62P49 INP/INM (2 Vpp 差分)
 ADS62P49 ──► DDR LVDS: 1 对 CLKOUT + 7 对数据/通道 ──► FPGA ISERDES

 FPGA OSERDES ──► 8 对 LVDS 数据 D[7:0] + DATACLK + FRAME ──► DAC3283
 DAC3283 IOUTA/B ──► 变压器差分转单端 ──► 重建低通滤波 ──► DAC (SMA)

 TRIG (SMA) ──► 比较器/缓冲 ──► FPGA 专用时钟脚(FMC150 中走 CLK1_M2C)

 FPGA SPI(共享 SCLK/MOSI,独立 SDO/使能)──► CDCE72010 / ADS62P49 / DAC3283 配置
```

要点(均有文档依据):

1. **时钟层次**:CDCE72010 将外部参考(或板载晶振)锁定到 491.52 MHz VCXO,再按 /1、/2 分频分配——DAC 得 491.52 MHz(2x 插值后数据率 245.76 MSPS),ADC 得 245.76 MHz,两者严格同源、整数比,便于收发环回与相参处理(✅ 分频关系见 [DS-CLK];频率计划为 FMC150 惯例,🔶)。
2. **ADC→FPGA**:ADS62P49 在 DDR LVDS 模式下每通道输出 7 对数据 + 1 对随路时钟,FPGA 端用 ISERDES + IDELAY 做字对齐(可先让 ADC 输出 ramp 测试图样验证链路)(✅ [DS-ADC],FMC150 将其映射到 FMC 的 LA00_CC/LA01–LA14 [FMC150])。
3. **FPGA→DAC**:DAC3283 只有 8 对数据线,16-bit I/Q 按字节交织、DDR 传输;FRAME 指示样本边界,FIFO 吸收相位差;内置图样校验器可在联调时验证 LVDS 链路误码(✅ [DS-DAC])。
4. **配置总线**:三颗芯片共用 SPI(各自独立片选/使能与 SDO 回读),外加 RESET/PD/TXENABLE 等杂散控制线,由 FPGA GPIO 驱动(🔶,FMC150 即如此 [E2E])。

## 3. SMA 端口功能映射建议(SIG / DAC / CLK_IN / TRIG)

| SMA 口 | 方向 | 建议映射 | 电气特性与依据 |
|--------|------|----------|----------------|
| **SIG** | 输入 | ADS62P49 通道 A(或 A/B 各一口)模拟输入 | AC 耦合(变压器/巴伦单端转差分),满量程 2 Vpp 差分 ≈ +10 dBm@50 Ω;输入带宽 700 MHz,但欠采样需注意抗混叠滤波(✅ [DS-ADC];FMC150 模拟口即 AC 耦合 [FMC150]) |
| **DAC** | 输出 | DAC3283 IOUTA1/B1 经变压器差分转单端 + 重建滤波后输出 | 满量程 20 mA,50 Ω 双端负载下约 0.5 Vpp/单端(变压器结构决定);直流不通,输出含 fDAC 镜像,需低通(✅ [DS-DAC]) |
| **CLK_IN** | 输入 | CDCE72010 PRI_REF 外部参考/采样时钟输入 | 差分口可收 8 kHz–500 MHz;单端 LVCMOS ≤250 MHz;支持内部 50 Ω 端接偏置到 VBB,单端正弦 AC 耦合即可驱动(✅ [DS-CLK][SLAU250])。板载 100 MHz OSC 可作 SEC_REF,无外参考时自动/手动切换 |
| **TRIG** | 输入 | 不进时钟芯片,直接(经缓冲/电平转换)进 FPGA 专用时钟脚,做采集门控/同步触发 | FMC150 的外触发即映射到 FMC CLK1_M2C 专用时钟对(✅ [FMC150]);建议 3.3 V LVCMOS 电平、板上串阻 + 钳位保护(❓ zero0000 具体电平待实测) |

## 4. 阶段 5 实测 Checklist(示波器 / 信号源)

### 准备
- [ ] 仪器:≥500 MHz 带宽示波器(1 GHz 更佳)+ 50 Ω 输入或 50 Ω 通过式端接;信号发生器(≥250 MHz 正弦);万用表
- [ ] 上电前:测各 SMA 中心针对地电阻,确认无短路;记录各电源轨(预期 3.3 V / 1.8 V 等,✅ 两款转换器均为 3.3+1.8 V 双轨 [DS-ADC][DS-DAC])

### 4.1 时钟树(CDCE72010)
- [ ] 无外部输入上电,探 X1(491.52 MHz)输出是否起振(频率、幅度)
- [ ] 探 CDCE72010 各输出走线/耦合电容两端:确认 ADC 时钟(预期 245.76 MHz)与 DAC 时钟(预期 491.52 MHz)是否存在及电平类型(LVPECL 摆幅约 0.7–0.8 Vpp/单端;LVDS 约 0.35 Vpp)——注意 1 GHz 级信号需有源探头或 50 Ω 直连(❓ 分频计划待验证)
- [ ] CLK_IN 注入 10 MHz(或 100 MHz)0 dBm 正弦,观察 PLL_LOCK 指示/输出频率是否跟随锁定;比较有无外参考时输出相位噪声差异(✅ 锁定行为见 [DS-CLK])
- [ ] 若有 SPI 抓取条件:上电时嗅探 SPI,判断配置来自 EEPROM 还是主机每次下发(✅ 片内 EEPROM [DS-CLK])

### 4.2 ADC 链路(SIG → ADS62P49)
- [ ] 信号源经 SIG 注入 10 MHz、约 −1 dBFS(≈ +9 dBm 前需先确认前端衰减/变压器比,从小幅度起步)正弦
- [ ] 在 ADC 输入引脚附近探差分信号幅度,反推 SIG→ADC 的插损/增益与耦合方式(AC/DC)
- [ ] FPGA 侧抓数(或用示波器探 LVDS 数据对确认有翻转):验证采样率与 CLKOUT 频率一致(DDR LVDS 时 CLKOUT = fs/2 的位时钟关系,✅ [DS-ADC])
- [ ] 若可配置:开 ADC ramp 测试图样,验证 FPGA 反序列化与位对齐(✅ 寄存器 0x25,[DS-ADC][E2E])
- [ ] 扫频 1–100 MHz 记录幅频响应,估计前端带宽与抗混叠滤波器拐点

### 4.3 DAC 链路(DAC3283 → DAC 口)
- [ ] FPGA 输出单音(如 10 MHz 满码)或使用 DAC3283 内部测试功能;示波器 50 Ω 端接测 DAC 口幅度(预期数百 mVpp 量级,取决于变压器/滤波,❓ 待实测)
- [ ] 检查 TXENABLE 状态——为低时 DAC 无输出(✅ [DS-DAC])
- [ ] 用 LVDS 图样校验器(pattern checker)验证 FPGA→DAC 数据链路无误码(✅ [DS-DAC])
- [ ] 观察输出频谱(示波器 FFT 即可粗测):确认镜像抑制与重建滤波器截止

### 4.4 环回与触发
- [ ] SMA 短线 DAC→SIG 环回:发单音收数据,验证收发同源时钟下频率无漂移(相参性)
- [ ] TRIG 注入 3.3 V 方波(先 1 kHz 低速),示波器同时探 TRIG 与 ADC 数据有效/帧信号,确认触发极性与延迟;逐步提高频率测触发最小脉宽(❓)

## 5. 校准与安全注意事项

### 安全(防损坏)
1. **输入幅度上限**:ADS62P49 满量程仅 2 Vpp 差分;SIG 口注入前先按前端衰减折算,信号源从 −20 dBm 起步逐步加大,**切勿直接打 >+10 dBm**;绝对最大值以数据手册为准(✅ [DS-ADC])。
2. **直流分量**:模拟口按 FMC150 惯例为 AC 耦合(🔶),但未确认前不要注入带直流偏置的信号;CLK_IN 同理,先用 AC 耦合正弦。
3. **DAC 输出保护**:DAC3283 为电流输出,输出脚电压必须保持在 AVDD±0.5 V 顺从范围内——**不要将 DAC 口对强源短接或接入有源电压源**(✅ 输出顺从范围 [DS-DAC])。
4. **探测 1.8 V LVDS/LVPECL 网络**时用高阻/有源探头,避免 50 Ω 直挂拉垮偏置;QFN 底部焊盘为地,探针防滑防短路。
5. **静电与热**:三颗芯片总功耗约 3.5 W,长时间调试注意散热;ESD 手环。
6. TRIG 口电平未确认前(❓)先用 3.3 V 以下、经 1 kΩ 串阻的信号试探。

### 校准
1. **ADC 直流失调**:ADS62P49 内置 DC 失调校正环路,可通过 SPI 使能自动收敛;也可采集空载数据求均值做数字扣除(✅ [DS-ADC])。
2. **ADC 增益/满量程**:0/3.5/6 dB 可编程增益改变满量程与 SNR/SFDR 折中,校准幅度响应时必须记录当前增益档(✅ [DS-ADC])。
3. **DAC 增益与 I/Q 平衡**:满量程电流由 BIASJ 电阻 + 数字粗增益决定(内基准 1.2 V ±5% → 增益误差 ±2 %FSR);双通道用作 I/Q 时启用 QMC 校正增益/相位/失调,压制镜像与本振泄漏(✅ [DS-DAC])。
4. **时钟质量决定 SNR 上限**:高输入频率下孔径抖动主导 SNR;CDCE72010 需配合低噪 VCXO 与窄环路带宽才能发挥抖动清除作用,更换 CLK_IN 源后应复测 SNR(✅ [SCAA090][SCAA092])。
5. **链路对齐**:环境温度变化会漂移 LVDS 时序,FPGA 侧 IDELAY 校准(ADC)与 FIFO/FRAME 对齐(DAC)应做成上电自校准流程,而非一次性固化常数(✅ FIFO 弹性缓冲机制 [DS-DAC])。
6. **相参测量**:校准频响/相位时确保 ADC/DAC 时钟同源于 CDCE72010(整数比 245.76/491.52),否则环回相位不稳定(🔶)。
