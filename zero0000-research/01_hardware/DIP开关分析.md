## 证据等级定义(与 BOM 一致)

| 等级 | 含义 |
|------|------|
| ✅ A | 丝印/照片清晰可读,且有交叉旁证,可直接采信 |
| 🔶 B | 照片可见或多文档一致,但缺独立旁证 / 细节存疑 |

### 与既有文档的矛盾裁决

1. **SW5 位数:2 位,非 4 位。** `BOM_证据分级.md` 第四节记"4 位(SW5 区)",但近拍丝印仅 `1 2` 两档、两只拨杆,且 `接口定义表.md`、`技术手册.md` 均记"SW5 ×2"。裁决:**以近拍为准,SW5 = 2 位** ✅;BOM 该行应在下次修订时更正。
2. **"SW45/46 区 2 位"** 仅见于 BOM 深化稿,本批照片无法定位,降级 ❓,列入近拍补拍清单(不排除系对按键位号 SW4x 的误读)。

## 二、功能假设(均 ❓ 待测,按先验可信度排序)

### SW5(2 位,FPGA 西南)

| # | 假设 | 依据 | 可信度 | 判别方法 |
|---|------|------|--------|----------|
| H1 | **时钟/参考源选择**(板载 X2 100 MHz ↔ 前面板 CLK_IN 外部参考,或 CDCE72010 参考切换) | 物理位置紧邻 X2 与时钟磁珠区;数采板常见"内/外参考"拨码 | 中高 | 断电量 SW5 至 X2 使能脚 / CDCE72010 REF_SEL 类引脚通断 |
| H2 | FPGA 配置模式位(M[1:0],JTAG ↔ Master SPI 切换,M2 硬线) | Kintex-7 板常规做法;但 SW5 距 FPGA 模式脚一侧与 Flash(U21,右区)较远,布线上偏弱 | 中 | 拨动后上电观察 DONE / JTAG 是否仍可配置;断电量至 FPGA M 脚 |
| H3 | 用户功能位(FPGA 普通 IO 读取:测试模式、环回、增益档) | 兜底假设,任何位置都成立 | 中 | JTAG 边界扫描定位(实验 E3) |
| H4 | 以太网 PHY strap / USB 通道选择 | 初稿曾列;但 SW5 距 U37(RTL8211F)与 U2(FT600Q)均远(对角),布局上不利 | 低 | 拨动后观察网口 link / USB 枚举变化 |
| H8-alg | **数据通路/DSP 旁路**(类 Avnet:直通 vs DDC/DUC)或环回 | Avnet FMC150 参考用 DIP 旁路 DUC/DDC;见算法假说 **H9**(`算法线索_资料对照.md`) | 中 | G3-DIP:改一位冷启动+同 Fin 收数对比谱/样率 |

### SW42(8 位,J12 扩展座旁)

| # | 假设 | 依据 | 可信度 | 判别方法 |
|---|------|------|--------|----------|
| H5 | **板卡地址 / ID 设定**(多板经 J12 级联时区分) | 紧贴 J12 扩展座;8 位正好一字节 ID | 中高 | 拨动后经通信协议读板 ID / 帧头字段变化 |
| H6 | 网口 IP 尾址或工作模式字(FPGA IO 读取) | 数采板常见;8 位可编码 IP 末段 | 中 | 拨动后 ping 扫描 / 抓包看源 IP |
| H7 | 调试/生产测试模式字 | 兜底 | 低 | 边界扫描 + 位流引脚约束比对 |

### 按键(非 DIP,一并登记)

| 按键 | 假设功能 | 可信度 |
|------|----------|--------|
| PROG_B | 拉低 FPGA PROGRAM_B,触发从 Flash 重新配置 | 高(丝印即 Xilinx 标准信号名)✅ 按丝印采信 |
| SYS_RST | 逻辑复位(FPGA 内部 GSR / 用户复位),不清空配置 | 中 ❓ |

## 三、验证实验(需实物;按"无损 → 上电"排序)

**前置红线:实验 E4 及之后任何拨动上电操作前,必须完成 Flash(U21 S25FL128S)全片备份**(见 `技术手册.md` 安全条目与 `02_firmware` 备份流程)。

| 编号 | 实验 | 步骤 | 判据 / 产出 |
|------|------|------|-------------|
| E1 | 出厂拨位存档(无损) | 微距拍摄 SW5、SW42 每一位杆位;记入本文件"出厂拨位"列 | 所有开关拨位 ✅ 级存档,作为复原基准 |
| E2 | 断电电气测绘(无损) | 万用表:每一位两端通断、各引脚对 GND / 3.3 V 电阻;重点核 SW5 附近 R221/R222 等是否为其上下拉 | 得到"开关-上下拉-目标网络"局部网表;可直接证伪/证实 H1(通向 X2/CDCE)与 H2(通向 M 脚) |
| E3 | JTAG 边界扫描映射(准无损) | 经 J13 用 SAMPLE 指令连续采样 FPGA 全部 IO;逐位拨动 SW5/SW42,找出电平翻转的 FPGA 引脚号 | 输出"开关位 → FPGA 引脚"映射表;与位流引脚约束(`scripts/search_net_constants.py` 扫描结果)比对可进一步反推网名 |
| E4 | 上电行为实验(有损风险,须已备份) | 从出厂拨位出发,**一次只改 1 位**,冷启动,依次观察:DONE 灯、USB 枚举(VID/PID **0403:601E**)、网口 link 与 IP、采集是否启动;每次实验后复原再改下一位 | 每位一行行为记录表;若某位使 DONE 不亮 → 强烈指向配置模式位(H2 成立) |
| E5 | 协议交叉验证 | 在 E4 各拨位下发读 ID / 状态命令,比对返回字段 | 判别 H5(板 ID)/ H6(IP 字) |

## 四、安全红线

1. **Flash 备份完成前禁止拨动任何 DIP**(与 `技术手册.md` 一致);E1/E2/E3 为断电或只读操作,不受限。
2. 每次实验后**立即复原至出厂拨位**并核对 E1 存档照片。
3. 勿以未验证的拨码组合长时间带载运行;出现 DONE 不亮/电源异常立即断电复原。
