# SMA 通道几何映射（照片 · P1.1 加强）

> 日期：2026-08-28  
> 范围：仅 s2056。依据现有 `assets/images/g2_probe_crops/` + BOM 丝印。  
> **不是**万用表蜂鸣；**不能**单独把 ADC A/B、DAC IOUTA/B 钉死到丝印。

---

## 1. 面板丝印顺序 ✅

BOM / 整板丝印（板边）：

`DAC2 / DAC1 / CLK_IN / TRIG / SIG2 / SIG1`

裁剪复核（`g2_crop_adc_left.jpg`）：

| SMA | 位号 | 照片 |
|-----|------|------|
| DAC2 | **J6** | 最上 |
| DAC1 | **J7** | 次上 |
| CLK_IN | **J8** | 红帽 |
| TRIG | （J9 类） | 红帽；同列 |

SIG2/SIG1 在同列更外侧（整板丝印 ✅；本裁剪未完整框入）。

---

## 2. DAC 出端几何（🔶 → 强旁证）

| 观察 | 证据 | 级 |
|------|------|----|
| DAC2(J6) 走线进 **U28**（小封装缓冲） | `g2_crop_adc_left` / `g2_tight_adc_u1` | 🔶 照片迹线 |
| DAC1(J7) 走线进 **U29** | 同上 | 🔶 |
| U28/U29 后接 **L2–L9** 电感阵列（重建滤波） | 同裁剪；与信号链 §2 一致 | 🔶 |
| 滤波簇朝 **U3 DAC3283** 模拟区 | `g2_tight_dac_u3` + 图27 同框 | 🔶 |
| U3 顶标 `DAC3283I`、位号 U3 | `g2_tight_dac_u3` | ✅ |

**假说（强 🔶，待蜂鸣）**：`DAC2↔U28↔一路 DAC 模拟出`，`DAC1↔U29↔另一路`。  
**未决**：哪一路是 IOUTA vs IOUTB（Conserviss FMC150 面板映射 **不可**照搬到本板丝印）。

## 3. ADC 入端几何（已有 BOM 旁证）

| 观察 | 级 |
|------|----|
| SIG1/SIG2 → **T5–T8** 四只 RF 变压器 → **U1 ADS62P49** | 🔶（BOM ✅ 旁证链） |
| U1 顶标 `AZ62P49` | ✅ |
| SIG↔通道 A/B 一一对应 | ❓ 须蜂鸣 / G3 单音 |

---

## 4. 对 P1.1 等级的影响

| 子项 | 升级后 | 说明 |
|------|--------|------|
| SMA 丝印存在与命名 | ✅ | 不变 |
| SIG→变压器→ADC / DAC→滤波缓冲→SMA 拓扑 | **强 🔶** | 本节几何 + 既有 BOM |
| 通道 A/B 与丝印一一对应 | 仍 ❓ | 须 G2 蜂鸣或 G3 单音鉴别 |

G0 命题「通道对应 SIG1/2、DAC1/2」的**拓扑半句**可标强 🔶；**引脚一一对应**半句仍 ❓ → 整命题记 **强 🔶**（未满 ✅）。

---

## 5. 有板最短关闭 ✅ 的动作

1. 断电：J6/J7 中心针 ↔ U3 IOUT 相关脚 / 变压器次级蜂鸣  
2. SIG1/SIG2 ↔ U1 INP/INM（A/B）蜂鸣  
3. 记入 `G2_时钟与SPI记录.md` 附录 + 本文件勾选
