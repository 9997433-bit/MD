## 2. 分块证据表

| 块 | 等级 | 依据 | 升到下一级 |
|----|------|------|------------|
| ADS62P49 / DAC3283 / CDCE / X1 | ✅/🔶 | BOM + 丝印 | — |
| SMA 丝印与变压器/滤波存在 | ✅/🔶 | 照片 | G2 蜂鸣通道对应 → P1.1 ✅ |
| ADC/DAC LVDS 电气族 | 🔶 | datasheet 排除法 | G2-5 边沿 |
| 采样/DACCLK 频率 | ❓ | 计划 A/B（R8/R10） | G2-2 |
| SPI 寄存器模式 | ❓ | 靶标表；位流无明文表 | G2-3/4 |
| DDR3 深缓冲 | 🔶 | 器件+带宽预算 | G3-5 |
| 抽取/NCO/FIR/FFT | ❓ | 仅假说 H2–H4 | G3/G4 矩阵 |
| 无 BRAM 驻留软核 | 🔶 | BRAM 候选区非零极少 | JTAG BRAM readback → 可更强 |
| FT600 / ETH 成帧语义 | ❓ | 硬件在板，协议未知 | G3-1 |
