# FMC150 参考设计 SPI/寄存器靶标检查表

> 适用对象:zero0000 板(Kintex-7 XC7K160T,固件 `20230825_s2056`)模拟前端  
> 板上已确认器件:**ADS62P49(ADC)+ DAC3283(DAC)+ CDCE72010(时钟)**,与 4DSP/Abaco FMC150 前端逐芯片同构(见 `OEM与datasheet线索.md`、`01_hardware/信号链_ADS62P49_DAC3283_CDCE72010.md`)。  
> 用途:**将来实物抓 SPI 总线 / FPGA ILA 观测 / 对照 HDL 源码**时的比对靶标。本表本身不构成任何"已实现"的证据。

---

## 1. 目的与证据等级约定

### 1.1 目的

1. 给出三片器件各自的 **SPI 电气/帧格式特征**,使逻辑分析仪抓到的波形能快速归属到具体芯片;
2. 列出 **公开可查的关键寄存器地址与典型上电配置**,作为"抓到的写序列是否像 FMC150 血统固件"的判定基准;
3. 提供 **可勾选的通过标准**,直接挂接 L4/L5 实测流程。

### 1.2 证据等级(沿用课题约定)

| 标记 | 含义 | 本表中的用法 |
|------|------|--------------|
| ✅ | 数据手册/官方文档原文 | 寄存器地址、帧格式、位定义 |
| 🔶 | 公开参考设计/论坛实测记录推断 | FMC150 典型初始化序列、频率计划 |
| ❓ | 待本板实测确认 | 本板固件**是否**执行这些写操作、具体写入值 |

**重要**:本表所有条目对 zero0000 板而言目前一律为 ❓——即"如果本板固件确实按 FMC150 路数配置前端,**应该**看到这些特征",而不是"已经看到"。

## 2. 总线拓扑靶标(FMC150 同构布线特征)🔶

FMC150 参考设计的 SPI 拓扑(来自公开 UCF/用户手册):**共享 SCLK + 共享 MOSI,每片独立的低有效使能(充当片选)与独立 SDO 回读线**,外加杂散控制线。抓 SPI 前先用万用表/示波器确认本板是否同构(❓):

| 信号类别 | FMC150 命名惯例 | 说明 |
|----------|-----------------|------|
| 共享时钟 | `spi_sclk` / `flp_com_sclk` | 三片共用 |
| 共享数据出(FPGA→器件) | `spi_sdata` / `flp_com_sdc2m` | 三片共用 |
| 片选/使能 | `cdce_n_en`、`adc_n_en`(`ads_n_en`)、`dac_n_en` | 各自独立、低有效 |
| 回读 | `cdce_sdo`、`ads_sdo`(ADC 的 SDOUT 引脚)、DAC 经 SDIO 或 ALARM_SDO | 各自独立 |
| 杂散控制 | `cdce_n_reset`、`cdce_n_pd`、`ref_en`、`adc_reset`、`txenable` | GPIO 驱动 |

> 注:原版 FMC150 还带一片 AMC7823 电压/温度监控(`mon_n_en`)。zero0000 板**未确认**存在该器件;若抓包发现第四路片选,应回头核对 BOM(❓)。

## 3. 器件靶标一:ADS62P49(双通道 14-bit 250 MSPS ADC)

### 3.1 SPI 模式 ✅

| 项目 | 特征 |
|------|------|
| 引脚（RGC-64 脚号） | **RESET=12, SCLK=13, SDATA=14, SEN=15, SDOUT=64**（✅ datasheet） |
| 帧格式 | **16 bit = 8 bit 地址 + 8 bit 数据**,MSB 先行 |
| 采样沿 | SDATA 在 **SCLK 下降沿**锁存;第 16 个下降沿整帧载入 |
| SCLK 上限 | 20 MHz |
| 进入串行模式 | 上电后 RESET 引脚需一个高脉冲(<1 ms),之后 RESET 保持低;若 RESET 恒高则为并行引脚配置模式(CTRL1–3) |
| 回读 | 写 0x00 寄存器 D0=1 使能后,SDOUT 输出被读寄存器内容 |
| 板上找点 | 先蜂鸣至上表脚号;飞线优先串阻见 `05_tests/G2_照片探针地图.md` §3 |

### 3.2 关键寄存器(公开地址)✅

| 地址 | 关键位 | 功能 | 抓包时的意义 |
|------|--------|------|--------------|
| 0x00 | D7=软复位(自清零);D0=串行回读使能 | 复位/回读 | 初始化序列**通常以写 0x00 开头** |
| 0x20 | D2=LOW SPEED 模式(fs≤80 MSPS 才用) | 速度模式 | 245.76 MSPS 方案下**应为 0** |
| 0x3F | D6–D5=基准选择(00 内部/11 外部);D1=双通道待机 | 基准/待机 | |
| 0x40 | D3–D0=掉电模式(1000 正常;1100 全局掉电;1111 CMOS 复用) | 电源模式 | 正常运行应写 0x08 一类 |
| 0x41 | **D7:0=并行 CMOS,1=DDR LVDS** | 输出接口 | FMC150 架构下**应置 1(如写 0x80)**——最强判据之一 |
| 0x44 | 输出时钟沿位置微调 | CLKOUT 相位 | 板级时序调优痕迹 |
| 0x50 | 数据格式(2s 补码/偏移二进制)、通道控制共用/独立 | 通道控制 | |
| 0x51 / 0x52 | 自定义测试图样低 8 位 / 高 6 位 | 测试图样值 | 联调痕迹 |
| 0x62 | D2–D0=通道 A 测试图样选择(全0/全1/toggle/ramp/自定义) | 测试模式 A | ramp/toggle 用于 LVDS 对齐调试 |
| 0x75 | D2–D0=通道 B 测试图样选择 | 测试模式 B | 同上 |
| 0x55 / 0x57、0x68 / 0x6A | 粗增益 / 细增益(+0.001~+0.134 dB,128 步) | 增益 | |
| 0x53、0x63、0x66、0x76 | 失调校正/杂项通道参数 | 校正类 | |

### 3.3 上电后"应看到"的配置特征清单 🔶(对本板均 ❓)

FMC150 类固件的 ADC 初始化足迹(一例公开配置见 TI E2E,地址集合比具体数值更稳定):

- [ ] SEN 有一串 16-bit 帧,首帧地址 0x00(复位);
- [ ] 写地址集合近似 `{0x20, 0x3F, 0x40, 0x41, 0x44, 0x50, 0x51, 0x52, 0x53, 0x55, 0x57, 0x62, 0x63, 0x66, 0x68, 0x6A, 0x75, 0x76}`(全部或大部分命中);
- [ ] 0x41 写入值 D7=1(DDR LVDS);
- [ ] 0x20 写入值 D2=0(高速模式,匹配 245.76 MSPS 时钟计划);
- [ ] 调试期固件可能对 0x62/0x75 写非零值(ramp=0x04、toggle=0x03 等),量产固件通常写 0。

## 4. 器件靶标二:DAC3283(双通道 16-bit 800 MSPS DAC)

### 4.1 SPI 模式 ✅

| 项目 | 特征 |
|------|------|
| 引脚（RGZ-48 脚号） | **TXENABLE=30, SDIO=31, SCLK=32, SDENB=33, ALARM_SDO=34**（✅ datasheet；同边连续簇）；可经 CONFIG23 `sif4_ena` 切 4 线制 |
| 帧格式 | **首字节为指令字节:R/W(bit7) + N1:N0(bit6:5,传输字节数-1) + A4:A0(bit4:0 寄存器地址)**,随后 1–4 个数据字节,MSB 先行 |
| 采样沿 | 输入在 **SCLK 上升沿**锁存;器件输出在下降沿给出 |
| 地址空间 | CONFIG0–CONFIG31(0x00–0x1F),共 32 个 8-bit 寄存器 |
| 板上找点 | `G2_照片探针地图.md` §3.5 |

### 4.2 关键寄存器(公开地址)✅

| 地址 | 名称(默认值) | 关键位 | 抓包时的意义 |
|------|----------------|--------|--------------|
| 0x00 | CONFIG0(0x70) | fifo_ena(b6)、fifo_reset_ena(b5)、multi_sync_ena(b4)、alarm 极性、**mixer_func(1:0)** | FIFO 模式与粗混频选择;SDR 类应用可能启用 fs/2、±fs/4 混频 |
| 0x01 | CONFIG1(0x11) | qmc_offset_ena、qmc_correct_ena、**fir0_ena/fir1_ena(插值 2x/4x)**、**iotest_ena**、twos | 插值倍数 = 判定 DAC 时钟计划(491.52 MHz @2x → 数据率 245.76 MSPS)的关键 |
| 0x02 | CONFIG2(0x00) | sif_sync、output_delay | 同步方式 |
| 0x03 | CONFIG3(0x10) | fifo_offset(2:0)、64cnt_ena、alarm 屏蔽 | FIFO 读指针偏移 |
| 0x04 | CONFIG4(0xFF) | coarse_daca(3:0)/coarse_dacb(3:0) | 输出满量程粗增益 |
| 0x05 | CONFIG5 | tempdata(7:0)(只读) | 若固件周期性**读** 0x05 → 温度监控在跑 |
| 0x06/0x07 | 报警标志/屏蔽 | FIFO 碰撞等 alarm 位 | 联调期常被轮询 |
| 0x09–0x10 | CONFIG9–16 | iotest_pattern0–7 | 配合 iotest_ena 的 LVDS 图样校验(误码测试足迹) |
| 0x12 | CONFIG18(0x02) | daca/dacb_complement、clkdiv_sync_ena | |
| 0x13 | CONFIG19 | multi_sync_sel、rev(总线反序) | FIFO 同步源选择(FRAME vs OSTR) |
| 0x17 | CONFIG23 | sif4_ena、clkpath_sleep_a/b | 3/4 线 SPI 切换 |
| 0x18 | CONFIG24 | sleepa/sleepb、clkrecv_sleep | 睡眠控制 |
| 0x19 | CONFIG25 | extref_ena | 内/外基准 |
| 0x1F | **VERSION31(0x12)** | clk_alarm(b7)、tx_off(b6)、**version(5:0)(只读)** | **读 0x1F 校验版本号是最常见的"SPI 通了没"自检**——高价值靶标 |

### 4.3 上电后"应看到"的配置特征清单 🔶(对本板均 ❓)

- [ ] SDENB 框住的帧首字节高 3 位呈 `0xx`(写)/`1xx`(读)模式,低 5 位落在 0x00–0x1F;
- [ ] 初始化序列覆盖 CONFIG0–CONFIG4 一带,且 CONFIG1 中 fir0_ena=1(2x 插值,匹配 491.52 MHz DACCLK / 245.76 MSPS 数据率的 FMC150 频率计划);
- [ ] 出现对 0x1F 的**读**操作(版本/时钟报警自检);
- [ ] TXENABLE 引脚在 SPI 配置完成、FIFO 对齐后才拉高(时序上晚于 SPI 序列);
- [ ] 联调期固件可能置 iotest_ena 并写 CONFIG9–16 图样(误码自测足迹)。

## 5. 器件靶标三:CDCE72010(10 路时钟同步/抖动清除器)

### 5.1 SPI 模式 ✅

| 项目 | 特征 |
|------|------|
| 引脚 | SPI_LE(锁存使能,低电平期间移位)、SPI_CLK、SPI_MOSI、SPI_MISO(独立回读) |
| 帧格式 | **固定 32 bit = 28 bit 数据 + 低 4 bit 地址,LSB 先行** ← 与另两片截然不同,是波形归属的第一判据 |
| 寄存器 | Reg0–Reg11 为配置(存 EEPROM);**Reg12(0xC)为状态/控制,仅 RAM** |
| 读命令 | 地址场 = 0xE(1110),目标寄存器地址放在数据场;回读数据 bit0 恒为 0(需忽略) |
| EEPROM 命令 | "Copy RAM→EEPROM–unlock"(命令字低字节 0x1F)可反复执行;"–lock"(低字节 0x3F)**一次性永久锁定** |
| 引导行为 | MODE_SEL=H 时为 SPI 模式;上电先从片内 EEPROM 加载配置——**即使 FPGA 不发 SPI,时钟输出也可能已经在跑** |

### 5.2 关键寄存器与状态位(公开信息)✅

| 地址 | 功能 | 抓包/回读要点 |
|------|------|----------------|
| Reg0 | 输入选择/输出0配置;**bit2、bit3 同置 1 = 参考自动选择(Auto)** | FMC150 案例中 Reg0 末位数值区分内钟/外参考方案 |
| Reg1–Reg7 | 各输出(Y1–Y7)电平类型(LVPECL/LVDS/LVCMOS)与分频 | 输出去向对照 `01_hardware/时钟树.md` |
| Reg8 | 输出8配置 + 反馈/杂项 | |
| Reg9 | 输出9/辅助输入配置 | |
| Reg10(0xA) | 电荷泵、PFD、M/N 分频高位 | 决定环路,内外参考方案差异最大的寄存器之一 |
| Reg11(0xB) | 分频/反馈设置、RESET_HOLD 模式 | |
| Reg12(0xC) | **bit4 INDET_AUX、bit5 INDET_VCXO、bit6 PLL_LOCK(只读);bit7 SLEEP;bit8 RESET_HOLD;bit10–12 版本号** | **读 Reg12 查 PLL_LOCK 是标准做法**——若固件轮询 0xC,强烈提示锁定检测逻辑存在 |

### 5.3 已知公开配置序列(比对靶标)🔶

FMC150 板上经 TI E2E 验证过的两套 28-bit 数据值(不含地址半字节),可作抓包比对模板:

| 寄存器 | 内部时钟(板载 VCXO 自锁) | 外部 10 MHz 参考 |
|--------|-----------------------------|-------------------|
| Reg0 | 0x683C034 | 0x683C038(Auto 模式则 0x683C03C) |
| Reg1 | 0x6800002 | 0x6800002 |
| Reg2 | 0x8380000 | 0x8380000 |
| Reg3 | 0x6800002 | 0x6800002 |
| Reg4 | 0xE980000 | 0xE980000 |
| Reg5 | 0x6800000 | 0x6800000 |
| Reg6 | 0x6800000 | 0x6800000 |
| Reg7 | 0x8380001 | 0x8380001 |
| Reg8 | 0x6800001 | 0x6800001 |
| Reg9 | 0x68050CC | 0x68050CC |
| RegA | 0x0FFC270 | 0x02FC07C |
| RegB | 0x0000828 | 0x00001C8 |
| RegC | 0x0000180 | 0x0000180 |

另:TI 出厂 EEPROM 默认配置(SCAA090,恰好按 **491.52 MHz VCXO** 预设,与本板 X1 频率一致)首字为 `REG0=0x002C0040`(32-bit 含地址)。若上电**没有任何 SPI 活动**但时钟已输出,应怀疑走的是 EEPROM 自举,此时可用读命令回读比对。

### 5.4 上电后"应看到"的配置特征清单 🔶(对本板均 ❓)

- [ ] SPI_LE 框住的帧恒为 32 clock;LSB 先行(波形上地址半字节出现在**帧头**);
- [ ] 若 FPGA 主动配置:一串 13 次写(地址 0x0–0xC 遍历),数值与上表某列高度相似;
- [ ] 若无写序列但时钟在跑:EEPROM 自举 → 用 0xE 读命令回读 Reg0–RegC 比对;
- [ ] 固件周期读 Reg12 检查 bit6 PLL_LOCK,或 PLL_LOCK 引脚接 FPGA;
- [ ] **不应**出现低字节 0x3F 的 EEPROM 永久锁定命令(若出现要立刻记录——不可逆操作)。

## 6. 抓包 / ILA 判定通过标准(可勾选)

### 6.1 波形归属判定(第一层)

- [ ] G1:总线上存在 **16-bit 帧、MSB 先行、下降沿采样** 的流量 → 归属 ADS62P49
- [ ] G2:总线上存在 **8-bit 指令字节 + N 字节数据、上升沿采样** 的流量 → 归属 DAC3283
- [ ] G3:总线上存在 **32-bit 帧、LSB 先行** 的流量 → 归属 CDCE72010
- [ ] G4:三路片选(低有效)与上述三类帧一一对应,SCLK/MOSI 共享 → 总线拓扑与 FMC150 同构成立

### 6.2 配置内容判定(第二层)

- [ ] A1:ADC 写序列命中 §3.3 地址集合 ≥12/18 项
- [ ] A2:ADC 0x41 写值 D7=1(DDR LVDS)
- [ ] D1:DAC 初始化覆盖 CONFIG0–CONFIG4,且 fir0_ena=1(2x 插值)
- [ ] D2:出现对 DAC 0x1F 的读操作,回读 version(5:0) 非全 0/全 1
- [ ] C1:CDCE 出现 13 写遍历(0x0–0xC)或 EEPROM 自举 + 回读可比对
- [ ] C2:CDCE 写值与 §5.3 任一列的逐寄存器汉明距离小(允许 Reg0/RegA/RegB 因参考方案不同而偏离)
- [ ] C3:Reg12 回读 bit6 PLL_LOCK=1(时钟树锁定)

### 6.3 系统级交叉验证(第三层)

- [ ] X1:CDCE 配置解出的分频计划与实测 ADC 时钟(预期 245.76 MHz)/DAC 时钟(预期 491.52 MHz)一致
- [ ] X2:DAC 插值设置 × DATACLK 实测频率 = DACCLK 实测频率
- [ ] X3:TXENABLE 拉高时刻晚于 DAC SPI 配置完成时刻
- [ ] X4:ADC 测试图样寄存器置 ramp 后,FPGA ILA 抓到的解串数据呈递增序列(链路对齐验证)

**判定规则**:G1–G4 全过 = "SPI 物理层同构 FMC150"(🔶→✅);再加 A/D/C 组各 ≥1 项 = "配置内容同构 FMC150 参考设计"(✅);第三层任一项通过即可为 L5 信号链实测放行。

## 7. 免责声明:静态位流无法证明已实现

1. 本表所有寄存器地址与配置值来自**公开数据手册与 FMC150 公开案例**,不来自对 `20230825_s2056` 位流的任何解码。**截至本表撰写,没有任何证据表明该位流内实现了上述 SPI 主控或使用了上述寄存器序列。**
2. Xilinx 加密/压缩后的静态位流不保留可直接检索的"寄存器写表";即使位流中搜到 0x683C 之类字节,也可能是巧合,**不得**据此声称命中。
3. CDCE72010 可 EEPROM 自举:即便实物上时钟正常,也不能反推固件里有 CDCE 配置逻辑——必须以抓包看到写序列或回读比对为准。
4. 本板与 FMC150 仅为 **BOM 同构**(🔶);布线、片选分配、寄存器数值完全可能被定制。本表任何一项不通过,只说明"与参考设计不同",不说明板卡故障。
5. 所有勾选项在获得实物证据(逻辑分析仪截图/ILA 波形/回读日志)之前,证据等级一律维持 ❓。
