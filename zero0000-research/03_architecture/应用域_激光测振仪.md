# 应用域先验 · 激光测振仪数字处理核心板（R13）

> 日期：2026-08-28  
> 来源：**用户口述**（非手册/非实测）——本板为**激光测振仪**数字处理电路的**核心板**；模拟信号经**滤波器**后再进入本板，由本板产出数据。  
> 范围：仅 `20230825_s2056` / zero0000。  
> 证据等级：应用域陈述 = **🔶 先验**；**不**因此把 P1.3/P1.4/P2.3/P2.4 标 ✅。

---

## 1. 系统位置（口述链路）

```text
激光测振光路/光电前端
        │
        ▼
   模拟滤波（板外或前端）
        │
        ▼
   本板 SIG SMA → ADS62P49 → FPGA 数字处理 → FT600/ETH → 主机「得到数据」
        │
        └─（可选）DAC SMA：监视/激励/校准/环回 —— 用途未测 ❓
```

与已有硬件证据相容：

| 已有事实 | 与测振仪角色 |
|----------|--------------|
| SIG1/SIG2 + 巴伦/变压器 → ADC | 滤波后 IF/基带模拟入板 |
| DAC1/DAC2 出板 | 可能为本振监视、校准音、激励——**勿**默认「任意波形播放仪」 |
| DDR3×2 + FT600 + ETH | 段采/连续流上传「振动数据」或 IF 原始样 |
| TRIG SMA | 外触发采集窗口（常见） |
| 位流无明文 FFT/DDC 字符串 | 仍可能有无符号硬 IP 或时域解调流水线 |

## 2. 对算法假说权重的调整（仍全部 ❓ 直至 G3）

激光多普勒测振（LDV）数字链常见能力（**行业通识 / 公开论文与专利，非本板证据**）：

| 常见块 | 行业先例 | 本板含义 | 假说影响 |
|--------|----------|----------|----------|
| 声光移频（AOM）载波 | 常见 **40–80 MHz** 量级 Bragg；采样需满足 Nyquist（例：IMEKO 文 ADC≥200 MSPS 对 90 MHz 上限） | 滤波后 IF 入 SIG；本板 ADC 最高 250 MSPS **能力够** | 钟族旁支加 **40.96 / 81.92**（491.52÷12/÷6）供 G2 识别（`g2_mode_infer`） |
| 数字下变频 / NCO·混频 | 专利 CN117109719 等：NCO→LPF→基带 IQ | 外差 IF → 基带 | **提高** H-DDC/NCO |
| CIC / 半带抽取 | 同上：降率后 CORDIC atan → 位移/速度 | 主机样率 ≪ 样钟 | **提高** P2.2 / H-FIR |
| CORDIC / 鉴相 | FPGA 实时解调常见 | 上传可能是速度/位移 | 勿默认「必是 ADC 码」 |
| 板内 FFT | 部分方案用；亦有论文主张**非 FFT**实时解调 | 谱可能在板或主机 | H-板内FFT 仍开放 |
| 纯原始 IF 上传 | 解调全在 PC | 段采 + DDR3 仍可能 | A′ 与 B/C **同级待验** |

**相对 R10 Conserviss「时域 AXI + 主机谱」**：测振仪语境下，**不再把「形态 A 纯直通上传」当作唯一最高先验**；改为：

| 形态 | 调整后先验（静态） | 理由 |
|------|-------------------|------|
| A′ 段采原始 IF → 主机解调/谱 | 高 | DDR3+FT600；位流无算法明文 |
| B/C 板内 DDC/解调 → 上传速度/位移/IQ | **升为与 A′ 同级待验** | 应用域 + 行业 FPGA 解调先例 + R5d（禁血统外推） |
| 板内 FFT 后只传谱 | 中 | 测振仪常见，须 G3 看帧是否 2ⁿ 谱 |

## 3. 对 G2/G3 实验的指向

| 阶段 | 因 R13 而优先的动作 |
|------|---------------------|
| G2 | 仍先测 C2/C3 + SPI（不变）；知应用域**不**替代钟/SPI；若见 **40.96/81.92** 勿当「出族」 |
| G3-2/3 | 注入**已知频率单音**（模拟滤波后的等效 IF，优先试 **接近疑似 AOM 载波±几 MHz**）→ 看上传是原始样、IQ，还是已是低频振动包络/速度 |
| G3 | 改 Fin：若峰跟着线性走且无固定差频 → 偏 A′；若出现固定 LO 差频/正交 IQ → 偏 H-DDC；若输出随振动台低频变而 IF 注入不变 → 偏已解调 |
| G3-4 | DAC 出：可能是校准/监视；用示波器看是否与 SIG 相干，**勿**先当任意波形源 |
| G4 | 矩阵 H-DDC / H-FIR / H-板内FFT / H-纯时域 按上表重排实验顺序 |

### 3b. R13b · 公开专利可核验频率（CN117109719B · 非本板）

> 来源：中国专利 **CN117109719B**《激光多普勒测振仪的振动速度解调系统及方法》（公开说明书摘录）。  
> 用途：只给 **G3 Fin / DAC 监视** 候选表与解调链**形态清单**；**禁止**写成「本板已实现该专利」。

公开可核验数字（专利权利要求/实施例）：

| 类别 | 数值 | 本仓用法 |
|------|------|----------|
| FPGA 方波 → 模拟混频本振候选 | **49 / 45 / 40 / 25 MHz** | G3-4 示波器看 DAC SMA 是否出现同族连续波（校准/LO 假说）；**不是** ADC 样钟 |
| 测量通道中心（模拟下变频后） | **50 / 25 / 10 / 5 / 1 MHz** | G3-2 Fin 优先扫这些邻域（±几 MHz），再扫 AOM 旁支 40–80 MHz |
| 数字解调链形态 | NCO 正交混频 → LPF → IQ → **CIC+HB(FIR)** 抽取 → **CORDIC** atan → 位移/速度 | 提高 H-DDC / H-FIR /「已解调上传」优先级；须激励证伪 |
| 抽取比（随量程） | 例：1 / 2 / 4 / 6（通道相关） | 仅作「主机样率 ≪ 样钟」时的对照句式，**不**填本板抽取比 |

与本板口述链路的差异（Must-2）：

- 专利有**板内模拟乘法下变频**；本板口述为**滤波后**再入 SIG → 模拟混频可能已在板外，本板可能只吃中频/基带。  
- 专利 LO 由 FPGA 方波产生；本板若用 DAC3283 出 LO，属**不同实现**，仅频率候选可借用。  
- **勿**把 25/40/45/49/50 MHz 写入 `g2_mode_infer` 样钟 FAMILY（那是 IF/LO，不是 CDCE 输出样钟）。

推荐 G3 Fin 顺序（有板后；脚本 `g3_tone_analyze.py --list-ldv-fins`）：

1. **10 MHz**（通用对照，便于估 fs）  
2. **25 / 40 / 45 / 49 / 50 MHz**（专利通道/本振邻域）  
3. **1 / 5 MHz**（低量程通道邻域；若上传已是低频速度会更显眼）  
4. 再扫 **±AOM** 区（约 40–80 MHz）看是否钉死差频

### 3c. R13c · 公开论文：板内反正切 + 相位解缠（非本板）

> 来源：蒲玲等，《一种激光多普勒测振相位解缠算法及 FPGA 实现》，《激光技术》2023, 47(5): 691-699（DOI 预览：`10.7510/jgjs.issn.1001-3806.2023.05.018`）。  
> 实验平台为 **Spartan-6 AX545 / XC6SLX45**，**不是**本板 XC7K160T。

可核验形态（行业先例）：

| 块 | 论文做法 | 对本板 G3 含义 |
|----|----------|----------------|
| 正交混频 + LPF | IF → 基带 IQ | 同 R13b；看上传是否成对 IQ |
| **CORDIC** 反正切 | 向量模式求相位 | 上传可能是**相位**而非 ADC 码 |
| **自动相位解缠** | 流水线统计跳变周期数 → 相位连续 | 若帧内见 ±π 跳变被抹平、或低频连续位移/速度，偏「已解调」；若仍是高频正弦，偏 A′ |
| 资源特征 | 解缠几乎不占存储 | 与本板「BRAM 软核不像」相容，**不能**反证有解缠 |

**Must-2**：禁止「有测振仪论文用 CORDIC/解缠 ⇒ 本板位流必有」。仅提高 G3 对「相位/位移上传」的检查优先级。

G3 附加判读（有收数后）：

1. 注入固定 Fin：若上传近似**直流+低频**且与 Fin 无关 → 疑已解调（速度/位移/解缠相位）。  
2. 若上传仍是 Fin 附近正弦 → 偏 A′ 原始 IF。  
3. 若见正交两路且相位差≈90° → 偏 IQ（DDC 后未鉴相）。  
4. 若单路序列在 ±π 附近周期性折叠 → 疑 atan **未**解缠；连续斜坡/锯齿补偿后 → 疑已解缠。

### 3d. R14 · 开源 FPGA 测振仪 HDL 形态（非本板）

> 来源：[Apollo3zehn/Vibrometer](https://github.com/Apollo3zehn/Vibrometer)（公开 RTL + UI；**Red Pitaya STEMlab 125-14 / Zynq**，片上 ADC≈**125 MSPS**，`adc_clk` 周期 8 ns）。  
> **不是** XC7K160T + ADS62P49/DAC3283/CDCE72010。只借**通路形态**给 G3/G4 判别。

可核验形态（README + `doc/flow_diagram.md` + `fpga/constraints.xdc`）：

| 块 | 该仓做法 | 对本板 G3 含义 |
|----|----------|----------------|
| 光电入 | 双 APD（正交延迟）→ 板载 ADC | 本板口述为滤波后 SIG；接口不同 |
| 主通路 | **条纹/极值计数**重建位移（非 NCO/CORDIC 主链） | 与 R13b/c 的 DDC·atan 链**并列**第三种解调形态 |
| 可选 | 微分滤波 → **板内 FFT** → AXI-Stream 开关 → **RAM DMA** | 加强「上传可为谱 / 位移 / 原始」多源切换假说（H-板内FFT、H1） |
| 自检 | 片内 DAC 发 FM；例载波相关 **400 Hz** → 谱峰 **200 Hz**（往返振动） | 有板后：若上传已是低频振动谱，可对照百 Hz 量级峰；**勿**当 IF Fin |
| 样钟 | 125 MHz 族 | **禁止**写入本板 `g2_mode_infer` FAMILY |

**Must-2**：禁止「开源 Vibrometer 有条纹计数/板内 FFT ⇒ 本板位流同构」。仅扩展 G3 判读分支：  
条纹计数（方向敏感极值） vs NCO→IQ→atan（R13b/c） vs 原始 IF（A′）。

### 3e. R14b · 带通采样反正切（公开论文形态 · 非本板）

> IEEE IoT 2025 *Improved Digital Arctangent Demodulation…*（DOI `10.1109/jiot.2025.3559611`）：用**特殊 Nyquist/带通采样 + 延迟造正交**再 atan/解缠；振动例 **500 Hz–1 MHz**。  
> 含义：G3 若见「无 NCO 痕迹但仍有正交/相位」勿只认 DDC；仍**禁止**血统断言。

## 4. Must-2 纪律（新增）

| 禁止 | 理由 |
|------|------|
| 「激光测振仪 ⇒ 板上一定有 FFT/DDC」 | 应用域只改**优先级**，不改证据等级 |
| 「有滤波器 ⇒ 板内必有数字 FIR」 | 滤波在板外口述；板内 FIR 仍须 SPI/激励证明 |
| 「得到数据 ⇒ 已是位移/速度工程单位」 | 可能仍是 ADC 码或 IQ；须解析帧格式（P2.6） |
| 「CN117109719 有 NCO/CORDIC ⇒ 本板同构」 | 公开专利 ≠ 本板 RTL；只借 Fin/形态清单（§3b） |
| 「激光技术 2023 解缠论文 ⇒ 本板有解缠」 | R13c：不同 FPGA 平台；只借 G3 判读句式（§3c） |
| 「Apollo3zehn/Vibrometer ⇒ 本板同构」 | R14：Red Pitaya 125 MSPS；只借条纹计数/板内 FFT/多流切换判读（§3d） |
