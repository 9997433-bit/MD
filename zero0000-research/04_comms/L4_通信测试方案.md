# L4 通信测试方案（无实物可先准备）

## 目标
打通 PC ↔ 板卡至少一条通路（优先 USB3/FT600；次选以太网）。

## 无实物准备清单
- [ ] 安装 FTDI **D3XX** 驱动/库；准备 PyD3XX 或 C 示例
- [ ] Linux udev：匹配 `0403:601e`
- [ ] 编写：枚举 → 打开 → ReadPipe(0x82)/WritePipe(0x02) 最小脚本（见 `scripts/ft600_scaffold.py`）
- [ ] 准备 Wireshark + 网线；规划固定 IP / DHCP 探测脚本（见 `scripts/udp_probe.py`）
- [ ] 阅读 `04_comms/USB_FT600Q.md` 与 `以太网通路研究.md`
- [ ] **SPI 被动嗅探准备**：对照 `03_architecture/FMC150_SPI靶标检查表.md`（L4 前置、零风险）
- [ ] **串口备选**：U33=TRS3221I，4-pin 座可能出调试 UART/RS-232（电平转换后接 PC）

## 有实物步骤（USB 优先）
1. 外接电源上电（见电源树安全项；Vin 宜 ≤12V，注意 TPS74401 上游 ≤5.5V）→ 再插 USB3  
2. `lsusb -v` / USBView：确认 `0403:601e` 且 SuperSpeed  
3. D3XX 枚举成功  
4. 回环或读持续流：记录吞吐、误码  
5. （可选并行）逻辑分析仪挂三片 SPI，按 FMC150 靶标表勾选「波形归属」层；或探测 U33 旁串口  
6. 失败则查线缆/口速/模式 GPIO  

## 判定标准（最低通过线）

| 接口 | 通过 | 失败 |
|------|------|------|
| USB | `lsusb` 见 `0403:601E` SuperSpeed；D3XX 打开成功；回环或持续读 **误码=0** 且稳定 ≥10 s | 仅 High-Speed、打不开设备、持续断流 |
| ETH | link up；ARP/ping 或自定义 UDP 探针有响应（见 `udp_probe.py`） | 无 link、无任何应答 |
| 串口（可选） | U33 旁 4-pin 测到有效 RS-232/UART 帧 | 无电/无数据 |

吞吐：USB 段采集场景目标 **≥50 MB/s** 即可记「可用」；满速 ADC 流不作为 L4 必达（受 DDR 缓冲架构限制）。
