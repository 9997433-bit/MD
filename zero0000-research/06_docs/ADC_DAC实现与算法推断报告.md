## 2. 问题① — ADC/DAC 如何实现（展开）

### 2.1 模拟前端拓扑 —— **强 🔶**

- SMA 丝印：`SIG1/SIG2/DAC1/DAC2/CLK_IN/TRIG` ✅  
- SIG→T5–T8 变压器→ADS62P49；**DAC2=J6→U28、DAC1=J7→U29→L2–L9→U3**（`SMA通道几何映射.md`）  
- 通道 A/B 与丝印一一对应：须 G2 蜂鸣 → 升 ✅  

### 2.2 数字接口 —— **强 🔶**

- datasheet 排除法 + LVDS 串阻簇照片；G2-5 探 LVDS/FRAME 升 ✅  

### 2.3 时钟 —— ❓

- X1=491.52 丝印 🔶  
- **三先验**：  
  - 计划 A：ADC≈245.76、DACCLK≈491.52（旧 FMC150 口头惯例）  
  - 计划 B：ADC≈245.76、**DACCLK≈245.76**、DAC **2x**→数据率 122.88（`G1_FMC150_VC707对照.md`，Conserviss **硬件回读**）  
  - 计划 C：ADC≈**61.44**、DACCLK≈**245.76**（RHINO 论文 §5.1.1 / R5c；`decode_cdce_profile --profile rhino_61m44`）  
- **旁支（R5b）**：122.88 / **163.84(=491.52÷3)** ——G2 族识别已覆盖；**非** A/B/C 主先验  
- TSW4200 支持 ADC 245.76；**不得默认 DACCLK=491.52**  
- G2-2 测 C2/C3（及 C6 DATACLK→插值比）裁决 A/B/C（或旁支）；`--demo-plan-c` 仅验证管线  
- 计划 C 下**勿**照搬 Conserviss「数据率 2:1 ⇒ 直通须抽」句式（见 `G3G4` §4.1）

### 2.4 SPI 工作模式 —— ❓

- 判据：ADC 0x41 / 0x50；DAC CONFIG1（Conserviss=`0x21` 2x+twos）；CDCE 全表（注意 Reg0=`683C035` ≠ 旧 E2E `683C034`）  
- 工具：`decode_spi_capture.py --auto-map` + `ingest_g2_inbox.py` + `G2_当日执行包.md`  
- 飞线：`G2_照片探针地图.md` — 先蜂鸣 **R83/R88/R89/R105/R106**  
- 配置归属（P1.5）：EEPROM / FPGA RTL / 主机 — 仅上电嗅探可裁决；Conserviss 参考实现 = control IP 自动 SPI  
- 静态否定：FMC150 E2E / Conserviss 整表 CDCE 明文簇无；KC705_DDS MIF 无  

### 2.5 固件侧配置骨架 —— ✅（仅 FPGA 自举）

见 `板卡固件工作流程.md`：Master-SPI 自举 ✅；前端 SPI 外壳 ❓
