## 2. 问题① — ADC/DAC 如何实现（展开）

### 2.1 模拟前端拓扑 —— 🔶

- SMA 丝印：`SIG1/SIG2/DAC1/DAC2/CLK_IN/TRIG` ✅  
- SIG→T5–T8 变压器→ADS62P49；DAC3283→L2–L9 滤波+缓冲→DAC SMA 🔶  
- 通道 A/B 与丝印一一对应：须 G2 蜂鸣 → 升 ✅  

### 2.2 数字接口 —— 🔶

- datasheet 排除法已到顶；G2-5 探 LVDS/FRAME 升 ✅  

### 2.3 时钟 —— ❓

- X1=491.52 丝印 🔶；FMC150 E2E + TSW4200 双重先验支持 245.76/491.52  
- G2-2 测 C2/C3（及可选 C6 DATACLK→插值比）  

### 2.4 SPI 工作模式 —— ❓

- 判据：ADC 0x41 D7、DAC fir0/fir1、CDCE Reg0–C / LOCK  
- 工具：`decode_spi_capture.py` + `G2_当日执行包.md`  
- 配置归属（P1.5）：EEPROM / FPGA RTL / 主机 — 仅上电嗅探可裁决  
- 静态否定：FMC150 E2E 明文簇无；**KC705_DDS 上游整表 MIF 连续 blob 无**（`KC705_DDS_SPI_MIF对照.md` ✅）→ 非「照抄该公开工程 BRAM 表」 

### 2.5 固件侧配置骨架 —— ✅（仅 FPGA 自举）

见 `板卡固件工作流程.md`：Master-SPI 自举 ✅；前端 SPI 外壳 ❓

## 3. 问题② — FPGA 数据通路与算法（展开）

### 3.1 已有结构证据

| 块 | 等级 | 依据 |
|----|------|------|
| 定制逻辑为主、中高占用 | 🔶 | 非零帧 ~53% |
| 无大规模 BRAM ROM / 驻留软核 | 🔶 | BRAM 候选区非零 ~5.5 KB |
| DDR3 深缓冲很可能 | 🔶 | 器件+带宽 |
| DSP（NCO/FIR/FFT） | ❓ | 仅假说；MCS 字符串不可用 |

通路图：`FPGA数据通路假说框图.md`。

### 3.2 算法先验（非结论）

| 形态 | 含义 | 先验 |
|------|------|------|
| A | 段采/突发 + 时域上传，谱在上位机 | **较高**（DDR3+FT600） |
| B | DDC/NCO/FIR 中频 | 中（Avnet 血统；SW5 或可旁路→H9） |
| C | 应用级解调 | 低 |

假说 H1–H9：`算法线索_资料对照.md`。矩阵：`G3G4_算法判别矩阵.md`。

### 3.3 明确不能写的话

- 「本板用了 FFT/DDC」——无 G3/G4 实验前禁止  
- 「SPI 一定按 FMC150 / KC705_DDS 表初始化」——散点+整表 MIF 阴性已削弱明文 ROM 假说，但仍可能运行时拼帧或 EEPROM
