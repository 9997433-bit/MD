## 2. Step 2 确认 Vin 候选（断电，万用表）

**做什么**：

1. 万用表通断挡：输入白座正负极 ↔ C388 正负极，确认极性走向与 D4 方向。
2. 量输入正对 GND 电阻（>百欧级为正常；接近 0 Ω 为板级短路）。
3. 顺带蜂鸣：U4 输出电感 L15（`472`）下游 ↔ U10/U11 IN 是否连通（验证「U4≈5V → TPS74401」链路，电源树 S7.3 待办）。
4. 看板上/外壳有无电压丝印或标签；有则以丝印为准（仍须 ≤16 V）。

**预期**：极性明确；输入对地无短路；Vin 候选锁定为 **5 V 或 12 V**。

**失败怎么停**：输入对地近 0 Ω → **禁止上电**，登记后转硬件排查。

**记录表**：

- [ ] 输入极性：正=`__` 脚，负=`__` 脚
- [ ] 输入对地电阻：`____` Ω
- [ ] L15 下游 ↔ U10/U11 IN：通 / 不通
- [ ] Vin 候选：5 V / 12 V / 丝印标注 `____` V

## 3. Step 3 限流上电与电源轨速测

**做什么**：

1. 电源设 **5.0 V / 限流 0.5 A**，SW1 置 OFF 接线 → 拨 ON 上电。
2. 观察电流：若持续顶在限流值（恒流灯亮）→ 3 秒内断电；若电流稳定（典型数百 mA 内）→ 观察 LED/DONE 灯。
3. 5 V 下若 DONE 不亮且各 buck 无输出或明显欠压 → 断电，升到 **12.0 V / 限流 1 A** 重试。
4. 电压确定后，万用表速测并记录：U7 输出（疑 1.0 V）、U8 输出（疑 3.3 V）、U4/L15 输出（疑 5 V，**必须 ≤5.5 V**）、U10/U11 输出（C11/C213 处）、L18/L19/L20 输出。

**预期**：某一档电压下电流稳定、DONE 灯亮（Flash 内固件自启动）；U4 输出 ≤5.5 V。

**失败怎么停**：

- 恒流/冒烟/异味/异响 → **立即断电**，当天到此为止，登记现象。
- U4 输出 >5.5 V 且连 U10/U11 → 立即断电，重查 §2 链路结论。
- 两档都稳定但 DONE 不亮 → 可继续 §4（JTAG 备份不依赖 DONE），但在记录表标注。

**记录表**：

- [ ] 采信 Vin = `____` V；稳态电流 = `____` A
- [ ] DONE 灯：亮 / 不亮；其他 LED：`________`
- [ ] 轨速测：U7=`____`V U8=`____`V U4=`____`V U10=`____`V U11=`____`V L18/19/20=`____/____/____`V
- [ ] 异常：无 / 有（`________`）

## 4. Step 4 Flash 全片只读备份（实物第一次必做，只读）

**做什么**：严格按 [SPI Flash 备份/烧录/回滚 SOP](../02_firmware/SOP_kintex7_spi_flash_backup_program_rollback.md) §2 执行：断电接 JTAG → 上电 → Vivado Hardware Manager `Auto Connect` 识别 `xc7k…` → 挂载 `s25fl128s`（按丝印选尾缀 0/1，弹窗 program 选 **No**）→ 全片读回 BIN → **读两次比对哈希** → 检查同步字 `AA 99 55 66` → 双处存档。

**工具/命令**：Vivado Hardware Manager（GUI 或 SOP 附录 Tcl）；`sha256sum flash_backup_a.bin flash_backup_b.bin`。

**预期**：识别到 `xc7k160t`；两次读回哈希一致；文件开头可见 `AA995566`。

**失败怎么停**：

- JTAG 识别不到 → 查线序/VREF/供电，降 JTAG 时钟 ≤6 MHz 重试；仍不行 → **停**，登记「JTAG 不可达」，后续任何写操作全部冻结。
- 两次哈希不一致 → 换短线/降频重读；备份未确认可靠前**禁止进入任何写流程**。
- 读回全 `FF` → Flash 型号尾缀选错，换另一条目重试。

**记录表**：

- [ ] 识别器件：`xc7k______`；Flash 丝印料号：`____________`（尾缀 0/1）
- [ ] 备份文件：`flash_backup_2026_____SN____.bin`，SHA256=`________`
- [ ] 双读哈希一致：是 / 否；同步字 `AA995566`：见 / 未见
- [ ] 已存两处（本机 + 仓库/NAS）：是 / 否

## 6. Step 6 L4 通信 · USB 优先（对应 U-A1）

**做什么**：按 [L4 通信测试方案](../04_comms/L4_通信测试方案.md) USB 路径：板卡外电已上 → 插 USB3 线到 PC。

**命令/工具**：

```bash
lsusb -v -d 0403:601e                          # 期望出现且为 SuperSpeed (5 Gbps)
python3 scripts/ft600_scaffold.py --list       # D3XX 枚举
python3 scripts/ft600_scaffold.py --read 1048576   # 从 Pipe 0x82 读 1 MB 试流
```

（Windows 用 USBView + FTDI D3XX Demo 等效；参考 [USB_FT600Q](../04_comms/USB_FT600Q.md)。）

**预期（L4 通过线）**：`0403:601E` SuperSpeed 枚举；D3XX 打开成功；回环或持续读 **误码=0 且稳定 ≥10 s**；吞吐 ≥50 MB/s 记「可用」。

**失败怎么停**：只到 High-Speed / 打不开 / 断流 → 换线、换 USB3 口、查模式 GPIO 各一次；仍失败 → **停止 USB 线，转 §7**，不做任何「重烧固件试试」的操作。

## 7. Step 7 L4 备选 · 以太网 / 串口（USB 失败才做）

**做什么**：

- **ETH**：接网线，看 link 灯；Wireshark 抓 ARP/DHCP；被动监听 `python3 scripts/udp_probe.py --port 50000 --seconds 10`，主动探测加 `--send-to <板卡IP>:50000`；参考 [以太网通路研究](../04_comms/以太网通路研究.md)。
- **串口**：U33 = TRS3221I，其旁 4-pin 白座疑 RS-232 调试口（[接口定义表](../01_hardware/接口定义表.md)）；示波器/USB-UART 先看 TX 有无波形，115200-8N1 起试。

**预期**：ETH link up 且 ARP/ping/UDP 探针有应答；或串口收到有效帧。任一成立即 L4 达标。

**失败怎么停**：ETH 无 link 且串口无电平 → L4 当天记「未通」，**不改 Flash、不拨 DIP**，把 §6/§7 记录表交静态侧分析（下一步靠 ILA/边界扫描或供货方资料）。若 L4 全失败，§8 仅做「DAC+示波器」路径（不依赖通信）或直接收工。

**记录表**：

- [ ] ETH link：up / down；应答：ARP / ping / UDP / 无
- [ ] 板卡 IP（若有）：`____________`
- [ ] 串口：TX 波形 有/无；波特率 `______`；内容样本：`________`
- [ ] 结论：ETH 通 / 串口通 / 均不通

## 8. Step 8 L5 最小功能实测 · ADC 或 DAC 二选一（对应 U-A2）

**做什么**：按 [L5 功能实测方案](../05_tests/L5_功能实测方案.md) 的最小路径，二选一即可：

- **路径 A（ADC，需 L4 已通）**：信号源出已知单音（幅度先小，< ADC 满幅，建议 −6 dBFS 级）→ SIG1 → 经 USB/ETH 收数落盘 → `python3 scripts/l5_fft_check.py <数据文件> --fs <采样率>` 核对频率/幅度/SNR。
- **路径 B（DAC，L4 不通也可试）**：若上电固件自跑 DDS/测试波形，示波器直接看 DAC1/DAC2 有无输出；有上位机命令则下发波形。

**预期（最低通过线）**：ADC 频率误差 ≤1%、无削波、SNR 粗看 ≥50 dB；或 DAC 示波器读频误差 ≤1%、主峰清晰无满幅振荡。

**失败怎么停**：无数据/波形 → 检查 CDCE PLL_LOCK（可嗅探 SPI，见 [FMC150 靶标表](../03_architecture/FMC150_SPI靶标检查表.md)）与采样率假设各一轮；仍失败 → 记「L5 未通」，收工走 §9，**不试图改固件解决**。

**记录表**：

- [ ] 路径：A（ADC）/ B（DAC）
- [ ] 注入/输出频率设定 `______`，实测 `______`，误差 `____`%
- [ ] ADC：SNR≈`____` dB，削波 无/有；DAC：波形描述 `________`
- [ ] 数据文件/示波器截图已存档：是 / 否
- [ ] 结论：L5 通 / 未通
