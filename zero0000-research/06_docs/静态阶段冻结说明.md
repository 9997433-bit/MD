## 4. 实物到位后 Day-1 行动

按顺序执行,前两步完成前**禁止任何写入操作**:

1. **上电前检查**:外观、丝印复核照片勘误,确认输入电源规格(→ Q12),对照《风险与合规》过压/ESD 条目。
2. **Flash 全片备份**:按 `02_firmware/SOP_kintex7_spi_flash_backup_program_rollback.md` 执行,备份校验通过前不做任何写入。
3. **拨查 SW5 / 记录默认状态**:上电观察 LED 与默认行为(→ Q11)。
4. **打通一条通信链路**:优先 USB(FT600Q),备选 ETH,按 `04_comms/L4_通信测试方案.md`(→ Q13)。
5. **一次 ADC 或 DAC 实测**:按 `05_tests/L5_功能实测方案.md` 走通最小验证路径。
6. **回写文档**:更新未知问题清单、进度仪表盘与总报告,解除冻结。
