## 2. 阶段计划（B0–B5）

原则：**先穷尽离线二进制，再开电气门**；禁止跳过 B2 阴性边界去点名 FFT。

```text
B0 身份锚定 ──► B1 结构统计 ──► B2 符号/常量猎取 ──► B3 形态推断
                                                         │
                         ┌─────────────────────────────────┘
                         ▼
              B4 假说冻结 + 实测门禁清单 ──► B5 交接 G2/G3（或可选深度逆向）
```

| 阶段 | 名称 | 核心动作 | 产出 | Gate | 状态 |
|------|------|----------|------|------|------|
| **B0** | 身份锚定 | MCS→BIN；SYNC/IDCODE/CTL0/CMD | §0 表；`固件结构分析` / `位流特征` | 哈希+IDCODE 一致 | ✅ |
| **B1** | 结构统计 | 包类型、FDRI 帧数、非零帧比、CMD 序列 | `位流特征与软核线索.md` | 解析异常=0；帧数=器件规模 | ✅ |
| **B2** | 符号/常量猎取 | SPI 字、网常量、MIF 整表、ASCII/UTF-16、Hamming≤2 | `位流SPI常量搜索` / `网络常量` / `KC705_DDS_MIF` | 每类有报告；高辨识度成簇判定 | ✅ |
| **B3** | 形态推断 | BRAM 密度塌陷；与 BOM/带宽交叉 | `位流BRAM帧分析`；P2.1/P2.5 🔶 | 书面边界（非 Vivado map） | ✅ |
| **B4** | 假说冻结 | 把 B0–B3 译成 Q①/Q② 假说 + **禁止项** | 本文 §3–§4；挂钩 G0/G3G4 排除表 | 每子项有证据等级 + 下一实验 | ✅（本文） |
| **B5** | 交接/加深 | 默认交接 G2；可选第二 mcs 差分 / Vivado map | `G2_投放三步.md`；差分报告（若有） | inbox 实测或书面 STOP | ⬜ **当前门** |

## 3. 已冻结的二进制结论（B0–B3 摘要）

### 3.1 可写入答辩的 ✅ / 强 🔶

| 结论 | 级 | 证据 |
|------|----|------|
| 固件为 XC7K160T 完整、未加密、Master-SPI 单镜像 | ✅ | `analyze_bitstream.py` |
| 无明文器件名 / FFT·FIR 字符串 / 硬编码 IP·MAC | ✅ 阴性 | SPI/网络常量搜索 |
| 无 FMC150/Conserviss/KC705 公开 SPI·MIF **整表**拷贝 | ✅ 阴性 | SPI 常量 + MIF 对照 |
| RHINO_CALF NCO 字 `0x03200000`/`0x0CE00000` 无高辨识度簇 | ✅ 噪声/阴性 | `位流SPI常量搜索.md` §5e（R5d） |
| 逻辑占用中高（~53% 非零帧）；BRAM 内容区近空 | 强 🔶 | 帧统计 + BRAM 脚本 |
| 不像大规模 BRAM 驻留软核；倾向定制数据通路 | 强 🔶 | 同上 + 无网栈常量 |
| FPGA 自身配置来自 Flash SPI | ✅ | BSPI_READ；**不等于**前端三片 SPI 归属 |

### 3.2 二进制明确推不出（保持 ❓）

| 子项 | 为何推不出 |
|------|------------|
| ADC/DAC 实际 Hz | 无频率字面量；时钟在 CDCE/VCXO 物理域 |
| DAC 插值 1x/2x/4x 实值 | CONFIG 字未成明文簇；须 SPI 回读 |
| 前端 SPI 主是 RTL / EEPROM / 主机 | 三种相容；阴性只削弱「明文 ROM 表」 |
| 板内 NCO / FIR / FFT **有无** | 无网表；阴性 ≠ 排除硬 IP |
| FT600/ETH 帧格式 | 无协议魔数明文 |

### 3.3 关闭路径（不做空转）

| 路径 | 状态 |
|------|------|
| 公开 prjxray xc7k160t frame map | ❌ 库无此器件 |
| 用 xc7k70t tilegrid 外推 | ❌ 禁止 |
| 无新输入时重复阴性全库扫描 | ❌ STOP（`等待实物_STOP.md`） |
| demo/`examples` 回填 G0 | ❌ 禁止 |

## 4. 假说 → 实测门禁映射（B4 核心交付）

### 4.1 问题① — 实现

| 子项 | 二进制贡献 | 当前级 | **下一实验（门禁）** |
|------|------------|--------|----------------------|
| 模拟拓扑 | 无（靠照片/BOM） | 强 🔶 | 蜂鸣 A/B；G3 单音 |
| ADC DDR LVDS / DAC 8b+FRAME | 无直接比特；器件唯一接口 + 照片串阻 | 强 🔶 | G2-5 边沿 / ILA |
| 样钟 / DACCLK | 仅先验 A/B/C | ❓ | **测 C2/C3** → `g2_clocks.json` |
| 插值 | Conserviss 靶标 2x 假说 | ❓ | SPI CONFIG1 + **C6 DATACLK** |
| SPI 寄存器模式 | 靶标表；镜像无整表 | ❓ | **`spi_capture.csv`**（独立 SDO） |
| 配置归属 | 削弱明文 ROM；三态未决 | ❓ | 仅上电无主机 SPI ≥5 s |

### 4.2 问题② — 算法

| 子项 | 二进制贡献 | 当前级 | **下一实验** |
|------|------------|--------|--------------|
| 深缓冲 | 高占用 + DDR3 BOM + 带宽数学 | 🔶 | G3-5 连续 vs 触发 |
| 抽取 | 阴性不可证 | ❓ | 主机样率 vs C2；计划 B/C 勿混用 |
| NCO/FIR | 禁止点名；片内 DAC FIR ≠ FPGA | ❓ | G3 改 Fin；SPI fir 位 |
| FFT | 禁止点名；无明文 | ❓ | 上传是否 2ⁿ 谱 |
| 软核 | BRAM 近空 → 强 🔶 不像大 ROM CPU | 强 🔶 | ILA / 第二固件 |
| 主机协议 | 无魔数 | ❓ | FT600/ETH 抓包 |
