### C. 不建议再投入静态

| 项 | 原因 |
|----|------|
| 再扫位流字符串 / IP / IPv4/MAC | 已阴性，重复劳动 |
| 再猜 DIP 功能表 | 已有专项假设；关闭靠实测 |
| 公开网再搜 s2056 / H8.2.3 | 已穷尽；需非索引渠道或供货方 |
| 协议帧 / 寄存器 map 还原 | 无明文、无上位机、无抓包 |
| 软核有无「最终判决」 | 静态已给最强阴性；终判靠 readback/行为 |
| USB vs ETH 谁是主通道 | 必须上电 |
| TRIG / CLK_IN 电平 | 必须示波器 |
| H8.2.3 ↔ 固件官方对应 | 需供货方或板上读回 |

## 4. 建议怎么选

```
想「静态做满再停」 → 只做 S1 → S2 → S4，然后冻结不动。
想「尽快真掌握板卡」 → 停静态，等实物，走《静态阶段冻结说明》Day-1。
无新资料又「继续」   → 按 STOP / 冻结策略：不扩边界、不重开扫描舰队。
```
