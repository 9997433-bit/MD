# 无实物阶段验收标准

> 适用范围:zero0000 课题在**没有实物板卡**期间的静态档案工作(L0–L3 + L4/L5 方案 + L6 文档)。  
> 用途:判定"静态档案是否完成",据此决定**可结题**或**可暂停等实物**。  
> 证据等级沿用全课题约定:✅ 确认 / 🔶 推断 / ❓ 待证。

## 1. 判定原则

1. **不以实物结果为前提**:凡必须上电、连线、烧录才能得到的结论,一律不作为本阶段验收项;只要求"方案齐备、可直接执行"。
2. **证据等级完备**:每一条硬件/固件结论都必须标注 ✅/🔶/❓,不允许出现无等级的断言。
3. **推断可追溯**:所有 🔶 推断必须写明依据(照片编号、丝印、位流偏移、datasheet 章节等),他人可复核。
4. **未知显式化**:回答不了的问题不允许被略过,必须进入《未知问题清单》并标注"需实物"或"需资料"。
5. **新人可接手**:仅凭本仓库文档,一个未参与前期工作的人应能:复述系统架构、理解固件布局、在拿到板卡后按 SOP 直接开工。

## 4. 结题 / 暂停判定

### 4.1 判定为"静态档案完成,可结题"

同时满足:

1. 第 2 节 M1–M15 全部通过;
2. 结题结论明确声明:L4(通信打通)与 L5(ADC/DAC 实测)**未执行**,原因是无实物,方案已备;
3. 总报告中列出"实物到位后的最小验证集"(见 4.3),作为课题的显式遗留项。

### 4.2 判定为"可暂停等实物"

同时满足:

1. M1–M15 全部通过(与结题同一标准,静态部分不留尾巴);
2. 仓库处于干净状态:无未提交改动、无仅存在于本地的分析结果;
3. 《未知问题清单》中所有"需实物"条目已汇总,恢复工作时可直接按清单开工,无需重新梳理上下文。

> 两者的静态验收标准相同;区别仅在于课题定性——结题 = 以静态档案为最终成果交付;暂停 = 等实物后继续 L4/L5,再出终版报告。

### 4.3 实物到位后的最小验证集(本阶段只登记,不执行)

| 项 | 对应方案 | 关闭的未知问题 |
|----|----------|----------------|
| 上电前检查 + 输入电源规格确认 | 风险与合规 / 电源树 | Q12 |
| Flash 全片备份 | M7 SOP | — |
| USB 或 ETH 至少一条通路打通 | M9 | Q13 |
| ADC 或 DAC 至少一次实测 | M10 | — |
| SW5 / TRIG / CLK_IN 行为确认 | M9/M10 | Q11、Q14 |

## 5. 验收操作方式

1. 逐条核对第 2 节表格,在《不遗漏检查清单》同步更新状态;
2. 任一 M 项不满足:补齐后再验收,不允许"带病结题";
3. 验收通过后,在《课题总报告》头部记录验收日期、验收人与结论(结题 / 暂停等实物),并 commit 推送作为存档点。
