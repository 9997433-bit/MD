# 课题总报告（初稿）

## 1. 摘要
研究对象为 [Montyzhang/zero0000](https://github.com/Montyzhang/zero0000) 的 Kintex-7 高速收发/采集板：固件 `20230825_s2056.mcs` + 7 张 PCB 照片。  
**已确认**：目标 FPGA 为 **XC7K160T**，固件**未加密、单镜像**；硬件含 FT600 USB3、双 DDR3、千兆 PHY、ADS62P49/DAC3283/CDCE72010 信号链。  
**强推断**：应用域偏 **SDR/3GPP**；模拟前端血统接近 **Abaco FMC150**；`destly` 为同作者 USB 下载器固件，非同一目标板。

## 2. 确认结论 ✅
| 项 | 结论 |
|----|------|
| FPGA | XC7K160T，IDCODE `0x0364C093` |
| 位流长度 | 6,692,572 B = 未压缩标准长度 |
| 加密/多镜像 | 无 AES；WBSTAR=0，单镜像 |
| 主要外围 | FT600Q、IS43TR16128D×2、RTL8211FI、FL128 Flash、CDCE72010、DAC3283 |
| 时钟标志 | 491.52 MHz VCXO + 100/200 MHz |

## 3. 推断结论 🔶
- 491.52 MHz → 无线/SDR 采样率族  
- ADC=ADS62P49（丝印曾疑似 AZ62P49，待近拍）  
- 主数据口偏 USB3；网口偏控制/备用  
- 整板 = FMC150 类模拟前端 + K7+FT600 定制载板  
- destly（TopUsb4431 / XC3S200）= 烧录工具端
