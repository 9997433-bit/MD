## 1. 摘要

从**一份 `mcs` 固件 + 七张 PCB 照片**出发，已在无实物条件下完成硬件、固件、架构三层静态分析。核心判断：

- 这是一块 **Xilinx XC7K160T（Kintex-7）主控的双通道高速采集/激励板**：模拟前端 **ADS62P49 ADC + DAC3283 DAC + CDCE72010 时钟树**、USB3 桥 **FT600Q-B**、DDR3 缓冲 **IS43TR16128D ×2（共 512 MB）**、配置 Flash **U21 FL128SAIF00**、背面净轨 LDO **U10/U11 TPS74401** 均已交叉验证 ✅；以太网 PHY 为 RTL8211F 系 🔶（后缀待近拍）。**主芯片识别完成度 ≥90%。**
- 初稿两大争议项已裁决关闭：**USB 桥 = FT600Q-B（排除 FT232 假说）✅、ADC = ADS62P49IRGC（丝印 AZ62P49 与 TI 官方 marking 精确匹配，初稿"AZ6ZP49"系笔误）✅**，对应 Q08/Q09 关闭。
- 固件已解码到位：**目标器件、位流长度、未加密、单镜像**四项均已确认 ✅；E1 明文特征扫描已执行，**未发现 MicroBlaze/lwIP 等软核/协议栈字符串**（阴性，不排除软核）。🔶
- 模拟前端与 **4DSP/Abaco FMC150 参考设计逐芯片同构**，叠加 **491.52 MHz** 参考，应用域**偏软件无线电（SDR）/通信中频收发**。🔶
- **课题范围仅 `20230825_s2056.mcs` / zero0000**；不做 USB-4431 / destly（见 `00_meta/课题范围边界.md`）。
- **L4（通信实测）/L5（ADC/DAC 实测）需实物**；静态收窄（电源/布局）可继续。
一句话结论：**静态档案已达"新人可上手、有实物即可复现实验"的交付标准；剩余不确定性全部集中在需上电测量的时钟/电源/协议细节。**

## 3. 确认结论 ✅

均有照片丝印、数据手册或固件直接支撑，可直接引用：

1. **主控 FPGA = XC7K160T**：固件 IDCODE `0x0364C093` + 镜像 6,692,572 B 与该器件未压缩位流长度精确吻合，双证一致。
2. **固件未 AES 加密**：CTL0 寄存器 DEC=0，字节熵 ≈1.14 bit/byte（明显低于加密流）。
3. **单一镜像、无 multiboot**：WBSTAR=0，SYNC 字 `AA995566` 全片仅出现一次。
4. **配置方式为 Master SPI + 16 MB SPI NOR Flash（U21 = FL128SAIF00 ✅）**：Flash 占用 ≈6.4 MiB，16 MB 容量充足；Kintex-7 JTAG 独立于模式引脚，任何 Flash 内容都可经 JTAG 重写救回。
5. **模拟前端三件套顶标裁决完毕**：ADS62P49IRGC（U1，顶标 `AZ62P49` 与 TI SLAS635 封装附表 device marking 精确匹配；初稿"AZ6ZP49 待核"关闭）、DAC3283I（顶标直读，位号待补拍）、CDCE72010（U27，位号丝印清晰）——与 FMC150 参考设计逐芯片一致。
6. **USB3 桥 = FT600Q-B**（U2）：顶标四行 `FTDI / KQ1037 / FT600Q / 2115-B` 与官方 QFN-56 打标规范逐行吻合；板载 USB 3.0 Type-B 蓝色插座为 SuperSpeed 旁证；初稿 FT232 假说排除。
7. **DDR3 = ISSI IS43TR16128D-125KBLI ×2**（U14/U15）：两颗 ×16 拼 32-bit 总线，合计 **512 MB**，DDR3-1600。
8. **接口物理存在**：JTAG 座 J13（丝印 TMS/TDI/TDO/TCK/GND/VCC）、USB 3.0 Type-B 座、RJ45（HanRun HR871133CE 千兆一体化）、SMA ×6（板边丝印 `DAC2/DAC1/CLK_IN/TRIG/SIG2/SIG1`）、按键 `PRO_B`（=PROG_B）/SYS_RST 均照片可见。
9. **旧笔记 IDCODE `0x03631093` 有误**，已更正为 `0x0364C093`。
10. **U10/U11 = TPS74401**（3A 可调 LDO，VQFN-20）：图25 丝印+方形 QFN+无功率电感三重证据；排除旧记 TPS54425。
11. **U7/U8 = TPS53515**（12A 同步 buck）：S7 顶标清晰；两级电源 `Vin→buck→LDO` 成立。
12. **图25 A/B 镜像区配准（S6）**：A→CDCE72010、B→ADS62P49、第三区→DAC3283（非空贴装）。
> 已关闭的未知问题：Q05（目标器件）、Q06（加密）、Q07（多镜像）、Q08（USB 桥 = FT600Q-B）、Q09（ADC = ADS62P49）、Q15（491.52 MHz 指向 SDR/3GPP，强推断）。

## 4. 推断结论 🔶

有器件规格与布局位置支撑，但未经实物验证：

1. **主机数据通道**：FT600Q-B（16-bit FIFO，峰值 ≈200 MB/s，PID `0x601E`，D3XX 驱动）为高速流通道；RTL8211F 系 PHY 走 RGMII（该系列仅支持 RGMII ✅），千兆线速 ≈118 MB/s。两者均**低于 ADC 满速产出**（2ch×14bit×250MSPS ≈ 875 MB/s），故 **DDR3（512 MB）大概率承担段采集/缓冲回放**角色；GbE 更可能为**控制面 + 低速/抽取后数据面**。
2. **以太网 MAC 在 PL 内实现**（Kintex-7 无硬核 MAC ✅）；E1 扫描无 lwIP/MicroBlaze 明文特征，倾向**纯逻辑 MAC + 自定义 UDP**，非软协议栈。
3. **时钟拓扑**：X1 = 491.52 MHz VCXO 贴 CDCE72010 闭环，外部 CLK_IN 为主参考、板载 100 MHz 为副参考；ADC 得 245.76 MHz（÷2）、DAC 得 491.52 MHz，收发严格同源整数比。491.52 MHz = 16×30.72 MHz，是 SDR/3GPP 采样体系惯用频率。
4. **电源轨**：入口钽 16V 上限 → 宜 ≤12V；图28 顶面 buck（电感可见）→ **U10/U11 TPS74401 LDO**（Vin≤5.5V）净轨。LDO 反馈电阻 0402 不可读 → 输出候选 1.0/1.2/1.8/3.3V（见 `电源树.md` S1）；倾向 1.8V AVDD 或 MGT 1.0/1.2。DDR3 需 1.5V。
5. **整机定位**：**FMC150 参考设计 + FT600 USB3 载板的定制整合**；未发现同 BOM 公开成品。
6. **配置总线**：CDCE72010 / ADS62P49 / DAC3283 三片 SPI 从机由 FPGA 统一配置；CDCE72010 内置 EEPROM，可能上电自举默认时钟。
7. **DDR3 挂 FPGA MIG**，X3 = 200 MHz 供 MIG/IDELAYCTRL 参考。
8. **图25「大空区」**：S2 复核为正面 QFN 的背面去耦镜像，**不是**未贴装大 IC；真未贴装主要为电阻排选装位。

## 6. 系统架构

**信号流（采集方向）**：SMA 输入（SIG1/SIG2 ✅ 丝印）→ 前端变压器耦合（T5–T8 四只射频变压器 ✅）→ ADS62P49（DDR LVDS 🔶）→ FPGA ISERDES 解串/成帧 → DDR3 缓冲（MIG 🔶）→ FT600Q-B/USB3 或 RTL8211F/GbE 上传。

**信号流（激励方向）**：FPGA OSERDES → DAC3283（8-bit 字节交织 DDR LVDS 🔶）→ 变压器/重建滤波 → SMA 输出。

**时钟枢纽**：CDCE72010 锁定 491.52 MHz VCXO，向 ADC/DAC/FPGA 分配同源时钟。

**控制三层**：
- JTAG → FPGA：比特流下载、Flash 间接烧写、ILA 调试，最底层保底通道。✅
- FL128 → FPGA：上电 Master SPI 自举。🔶
- 主机 → FPGA：USB/以太网承载运行时命令，再经 SPI 配置三颗外设。❓（协议待抓包）

带宽瓶颈结论：**USB3/GbE 均 < ADC 满速产出 → 必须缓冲或抽取**，是判定"段采集 vs 连续流"的关键。🔶

（完整 Mermaid 框图、连线证据表、数据/控制链路详见 `03_architecture/L3_系统架构.md`。）

## 8. 应用域

三种假设及其判别路径：

| 假设 | 内容 | 静态证据倾向 |
|------|------|--------------|
| H1 高速数据采集卡（DAQ） | 双通道 250 MSPS 采集为主，DDR3 深存储段采集 | 🔶 |
| **H2 软件无线电收发（SDR）** | ADC 采中频、DAC 内插+粗混频发中频，收发同源，USB3 双向流 | 🔶 **当前倾向** |
| H3 通信/信号链测试仪 | 板内 PRBS/BER/回环逻辑，以太网控制面，TRIG 多板同步 | ❓ |

**倾向 H2 的依据**：491.52 MHz（SDR/3GPP 采样体系）、收发严格同源、FMC150 血统、双向 USB3。静态实验进展：**E1（mcs 特征串提取）已执行，位流中 ≥6 字符 printable 串为 0，无 DDS/PRBS/lwIP 等可判读明文**——属裸位流常态，H2/H3 判别无法由 E1 收口；**E2 部分完成**（SMA 面板丝印 `DAC2/DAC1/CLK_IN/TRIG/SIG2/SIG1` 已确认 ✅，芯片端走线待近拍）。剩余判别转入实物实验 E3–E7（详见 `03_architecture/L3_系统架构.md` §4 实验矩阵）。

## 10. 后续路线

**前提**：是否有实物决定 L4/L5；静态收窄不依赖实物。

- **无实物（当前）**：继续 S3/S6/S7/S8（FMC150 靶标、背正面配准、顶面 buck 识读、小逻辑入 BOM）——见 `静态分析剩余清单.md`。
- **有实物（推荐顺序）**：
  1. 确认输入电压 → 安全上电（注意 TPS74401 Vin≤5.5V，入口仍可能 5–12V）。
  2. Flash 只读备份 + JTAG Device ID。
  3. 测电源轨 / 时钟树。
  4. L4 打通 USB 或网口一条通路。
  5. L5 ADC/DAC 最小实测。

**成功标准**：主芯片 BOM ≥90%（**已达成** ✅）、框图/时钟/电源/链路齐全、固件可备份回滚、≥1 条通信 + ≥1 次 ADC/DAC 实测、文档可让新人上手。
