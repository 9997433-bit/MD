## ① ADC/DAC 如何实现

| 子项 | 当前答案 | 级 |
|------|----------|----|
| 芯片 | ADS62P49 + DAC3283 + CDCE72010 + X1=491.52 VCXO | ✅ |
| 模拟拓扑 | SIG→T5–T8→ADC；DAC2=J6→U28、DAC1=J7→U29→L2–L9→U3；A/B 引脚未蜂鸣 | **强 🔶** |
| 数字接口 | ADC→FPGA DDR LVDS；FPGA→DAC 8-bit LVDS+FRAME | 器件 **强 🔶** / 边沿 ❓ |
| 采样/更新钟 | **未测**。先验 **A**：ADC245.76 / DACCLK491.52；**B（Conserviss）**：双路245.76 + DAC 2x→数据率122.88；**C（RHINO）**：ADC61.44 / DACCLK245.76；旁支 122.88 / **163.84**(÷3) | ❓（先验 🔶） |
| 插值 | 先验 **2x**（A/B）；CONFIG1 Conserviss=`0x21` | ❓ |
| SPI 模式 | 靶标齐（含 Conserviss 全表）；位流无明文整表（逆向上限见 `位流逆向_能推出与不能.md`）；须 LA | ❓ |
| 配置归属 | FPGA 自举 ✅；前端 SPI = RTL / EEPROM / 主机 三态未决 | ❓ |

## ② FPGA 通路与算法

| 子项 | 当前答案 | 级 |
|------|----------|----|
| 总体 | 中高占用定制 fabric；倾向无 BRAM 驻留软核 | 🔶 |
| 缓冲 | DDR3×2=512 MB → 深缓冲/段采很可能（H1）；满速双通道原始连续上传**不像**（带宽） | 🔶 |
| 抽取 / NCO / FIR / 板内 FFT | **不能命名**；R13 下 A′（原始 IF 上传）与 B/C（板内 DDC/解调）**同级待验**；R10/R5d 仅作对照 | ❓ |
| 成帧/协议 | FT600+ETH 在板；帧格式未知（可能是码流/IQ/速度） | ❓ |
| 系统角色 | 滤波后模拟入 → 本板数字化处理 → 主机得数（测振仪核心板） | 🔶（口述） |

### 已排除（不像）

- 明文 FMC150/Conserviss/KC705 MIF ROM 整表拷贝  
- 大规模 BRAM 软核镜像；硬编码网常量栈  
- **归因陷阱**：DAC SMA 插值/混频 ≠ FPGA FIR/NCO；低主机样率 ≠ 必有 FPGA 抽取；FMC150 血统 ≠ 板内 FFT/DDC；**「测振仪」≠ 板上必有 FFT/DDC**（R13）  
- 经单路 GbE 连续满速双通道原始码流（带宽数学）  
- 在计划 B 下「无抽取 ADC→DAC 数字直通」；在计划 C 下**照搬** Conserviss 2:1 数据率抽取句式（R5c）
