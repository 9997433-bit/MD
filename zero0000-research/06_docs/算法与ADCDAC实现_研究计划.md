## 0. 问题拆解（先把「想知道」写成可验收命题）

### P1 — ADC/DAC「如何实现」（硬件+接口+工作模式）

| 命题 ID | 想确认的内容 | 最低成功标准 |
|---------|--------------|--------------|
| P1.1 | 模拟前端拓扑 | SMA→耦合→ADS62P49 / DAC3283→SMA 与照片一致；通道对应 SIG1/2、DAC1/2 |
| P1.2 | 数字接口 | ADC→FPGA 为 DDR LVDS；FPGA→DAC 为 8-bit DDR LVDS+FRAME（示波器或 ILA 见到边沿/帧） |
| P1.3 | 采样/更新时钟 | 测得 ADC 样钟、DAC DACCLK 实际频率（候选 245.76 / 491.52 MHz 族） |
| P1.4 | 器件工作模式 | SPI 抓到的寄存器：ADC DDR/增益；DAC 插值倍数、粗混频开关；CDCE 分频与 LOCK |
| P1.5 | 配置归属 | 上电后配置来自 Flash 位流内逻辑自动 SPI，还是主机事后下发 |

### P2 — 「用了什么算法」（FPGA 数据通路）

| 命题 ID | 想确认的内容 | 最低成功标准 |
|---------|--------------|--------------|
| P2.1 | 有无深缓冲 | DDR3 读写活动与段采/连续流行为可区分 |
| P2.2 | 有无抽取/重采样 | 主机侧样率 ≪ ADC 时钟，或寄存器/命令暴露抽取得数 |
| P2.3 | 有无数字下变频/NCO/FIR | 频谱平移、镜像抑制、滤波响应与激励频率的关系可复现 |
| P2.4 | 有无 FFT/检波等 | 上传数据已是谱/功率而非时域 IQ/实采样 |
| P2.5 | 有无软核调度 | ILA/总线看到 CPU 总线周期，或仅纯流水线 |
| P2.6 | 主机协议语义 | 命令→采/放/触发的状态机可画出 |

**证据等级**：每条结论必须标 ✅ / 🔶 / ❓，禁止无证据点名「一定是 FFT」。

### G4 — 算法判别矩阵（答「用了什么算法」）

对每个假设打分（0–2：无证据 / 弱 / 强），并设计**可证伪实验**：

| 假设 | 预期现象 | 证伪现象 |
|------|----------|----------|
| H-纯时域打包上传 | 改 Fin，数字谱峰跟着线性走；无固定本振差频 | 峰固定在某 IF 或已是幅度谱 |
| H-DDC/NCO | 存在可调 LO；镜像/边带可调 | 完全无复基带结构 |
| H-FIR/半带抽取 | 样率阶跃（÷2/÷4）；通带滚降 | 样率=时钟且无滚降 |
| H-板内 FFT | 上传长度固定 2^n 点谱；相位信息弱/无 | 连续时域流、可变长度帧 |
| H-PRBS/自检 | 无输入仍有确定性码型 | 无输入接近噪声底 |
| H-软核主控 | SPI/USB 命令延迟呈现软件抖动；BRAM/总线活跃 | 纯固定流水延迟 |

**G4 退出门禁**：矩阵填完；每个 H 标注保留/排除；总报告增加「算法结论」节（允许最终仍是 🔶 多假设并存，但必须写清证据）。
