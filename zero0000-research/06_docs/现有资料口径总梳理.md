## 1. 现有资料已锁定的结论（✅）

| 类别 | 结论 |
|------|------|
| FPGA | XC7K160T FFG676；位流 IDCODE `0x0364C093`；长度匹配未压缩全镜像 |
| 固件 | 未 AES 加密；单镜像；Master SPI 引导头齐全 |
| Flash | U21 Spansion **FL128SAIF00**（16 MB） |
| USB | FT600Q-B；板载 **USB3 Type-B ×1**（非双座/非 Type-A） |
| ADC/DAC/时钟 | ADS62P49、DAC3283（**U3**）、CDCE72010；OEM≈FMC150 |
| 时钟源 | 491.52 MHz VCXO + 100 MHz + 200 MHz → 偏 SDR/3GPP |
| 存储 | DDR3 IS43TR16128D ×2 → 512 MB |
| 以太网 | **RTL8211FI-CG** + HanRun 千兆 magjack |
| 电源 | U7/U8=TPS53515；U10/U11=TPS74401；U4 疑 TPS54620；入口钽 16 V 上限 |
| 其它 | U32=74LVC138A；U33=TRS3221I（RS-232）；SW5=2 位 DIP |
| 布局 | 图25「大空区」= 正面 IC 背面去耦镜像（A→CDCE、B→ADC、第三→DAC） |
| 软核/协议明文 | 位流字符串扫描阴性（不能证伪小核） |
