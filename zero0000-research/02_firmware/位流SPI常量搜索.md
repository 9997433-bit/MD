# G1 加深：位流 SPI 配置常量搜索

> 日期：2026-08-28  
> 范围：仅 `20230825_s2056` / zero0000。不做 4431。  
> 脚本：`scripts/search_spi_constants.py`（可复现）  
> 靶标来源：`03_architecture/FMC150_SPI靶标检查表.md` §3–§5（TI E2E / SCAA090）

---

## 1. 问题

公开 FMC150 类固件常把 CDCE/ADC/DAC 初始化表放在 FPGA **BRAM/ROM 常数**里，上电由纯 RTL SPI 状态机逐字写出（见 `算法线索_资料对照.md` R5）。  
若本板同源，镜像中可能以明文出现：

| 类型 | 示例 | 辨识度 |
|------|------|--------|
| CDCE 完整 SPI 字 `(data28<<4)\|addr` | 内部时钟 Reg0 = `0x683C0340` | **高**（Reg0/A/B 尤其） |
| CDCE SCAA090 出厂字 | Reg0 = `0x002C0040` | 中 |
| ADC 16-bit 帧 | `0x4180`（DDR LVDS） | **低**（16-bit 在压缩位流中噪声极大） |
| DAC 指令+数据 | `0x0111` 等 | 低 |

**命中 ≠ 本板已启用该配置**；但「高辨识度字完全缺失 + 无成簇」可加强「不以明文 FMC150 写表存放」的先验。

---

## 2. 方法

```bash
python3 scripts/parse_mcs.py assets/firmware/20230825_s2056.mcs --extract-bin /tmp/s2056.bin
python3 scripts/search_spi_constants.py /tmp/s2056.bin --json /tmp/spi_const_report.json
```

镜像大小：6 692 588 bytes。对每条靶标做 BE32/LE32（ADC/DAC 为 BE16/LE16）全文搜索；另做「±128 字节窗内 ≥3 个不同 CDCE 寄存器」成簇检测，以及 Reg0/A/B 高辨识度三元组共窗检测。

---

## 3. 结果（可复核）

### 3.1 高辨识度 CDCE 字 —— **全部未命中**

| 靶标 | full32 | BE | LE |
|------|--------|----|----|
| 内部 Reg0 | `0x683C0340` | 0 | 0 |
| 内部 RegA | `0x0FFC270A` | 0 | 0 |
| 内部 RegB | `0x0000828B` | 0 | 0 |
| 外部 Reg0 | `0x683C0380` | 0 | 0 |
| 外部 Reg0 Auto | `0x683C03C0` | 0 | 0 |
| 外部 RegA | `0x02FC07CA` | 0 | 0 |
| E2E 变体 RegA `05FC270` / `47FC752` / `0BFC07C` | （对应 full32） | 0 | 0 |

（低熵变体如 `0x0000800` 不做肯定/否定依据，易与配置噪声碰撞。）

### 3.2 成簇检测 —— **无**

- 「同字节序、128 字节窗、≥3 个不同 Reg」：**0 簇**
- Reg0/A/B 高辨识度三元组共窗：**无**

### 3.3 低辨识度 / 噪声命中（不升级证据）

| 项 | 观察 | 判读 |
|----|------|------|
| CDCE Reg2/8/C 等较泛化 full32 | 散点 1–3 次 | 与随机/配置帧碰撞相容；**不构成写表** |
| SCAA090 `0x002C0040` | BE×2、LE×1 | 弱；无相邻 Reg1… 序列 |
| ADC `0x4180` | BE/LE 各 ≥64（脚本封顶） | **16-bit 噪声**，不可用作肯定证据 |
| ADC ramp `0x6204` 等 | 十余次量级 | 同上 |

## 4. 对命题的影响

| 命题 | 本轮是否升级 | 说明 |
|------|--------------|------|
| P1.4 器件工作模式 | **否**（仍 ❓） | 未见明文写表 ≠ 无 SPI；EEPROM 自举或运行时拼帧仍可能 |
| P1.5 配置归属 | **弱旁证 🔶 方向**（表内仍标 ❓，旁证写入下栏） | 「位流内无 FMC150 明文 13 字表」与三种候选仍相容，但**削弱**「ROM 常数表照抄 E2E」假说 |
| P2.5 软核 | 不改 | 与「纯 RTL 状态机即时拼帧」仍相容 |
| H5/H6/H8 | 不改等级 | H8 的「写值比对」仍必须以 G2 抓包为准；本轮只说明**不能**指望在 MCS 里直接读出那张表 |

**旁证句（可引用，禁止写成 ✅）**：

> 在 `20230825_s2056` 线性镜像中，FMC150 公开「内部/外部」CDCE 高辨识度寄存器字（Reg0/A/B）**零命中**，且不存在 ≥3 寄存器成簇；因此**不支持**「位流以明文 ROM 存放与 E2E 帖相同的 CDCE 初始化表」这一细假说。SPI 主控是否存在、实际写入值是什么，仍只能由 G2 被动嗅探裁决。

## 5. 加深：KC705_DDS 整表 MIF 连续blob（2026-08-28）

单字扫描之外，对 [samprager/KC705_DDS](https://github.com/samprager/KC705_DDS) 上游 `.mif` **整表**做连续字节搜索（LE/BE）：

- 文档：`02_firmware/KC705_DDS_SPI_MIF对照.md`
- 脚本：`scripts/search_fmc150_mif_rom.py`
- 结果：ADS/DAC/CDCE(int+ext) **full_hits=0**，最长前缀 ≤2 → **✅ 否定**「照抄该工程 BRAM INIT 写表」

这比 §3 的「散点/成簇」否定更强：连参考设计自己的连续 ROM 形态也不在镜像里。

## 5b. Conserviss 高辨识度字 · Hamming≤2（2026-08-28 · 一次性）

> 靶标：Conserviss `C_CDCE_INTERNAL_245M76` 全字 `(data28<<4)|addr`：Reg0=`683C0350`、RegA=`05FC270A`、Reg2=`83800002`、Reg4=`E9800004`。  
> 方法：对 `20230825_s2056.bin`（6 692 588 B）逐字节 BE/LE 解释 32-bit，计 Hamming 距离；另检 256 B 窗内 **≥2 个不同寄存器** 且各 ≤1 bit 翻转的近邻簇。  
> **未**新增常驻扫描脚本（STOP：避免空静态舰队）；本轮为一次性核验，结果如下。

| 靶标 | exact BE/LE | ham1 BE/LE | ham2 BE/LE | 判读 |
|------|-------------|------------|------------|------|
| Reg0 `683C0350` | 0 / 0 | 0 / 0 | 0 / 0 | 高辨识度；≤2 bit 翻转亦无 |
| RegA `05FC270A` | 0 / 0 | 0 / 0 | 0 / 0 | 同上 |
| Reg4 `E9800004` | 0 / 0 | 2 / 0 | 34 / 16 | 中低熵；散点噪声级 |
| Reg2 `83800002` | 0 / **1** | 47 / 32 | 813 / 857 | 低熵（多零）；LE exact@3028317 与既有散点同族，**不成簇** |

- 均匀噪声下 ham≤2 期望量级 ≈0.8 次/靶标/字节序；Reg0/RegA 实际 **0** 与「明文近邻拷贝」不相容。  
- **ham≤1 多寄存器共窗簇 = 0**。  

**结论**：在「偶发 1–2 bit 损坏仍可认出 Conserviss 表」假说下仍阴性 → 进一步加强「非 Conserviss/E2E 明文 ROM 写表」；**不**升 P1.4（运行时拼帧仍可能）。

## 5c. ASCII / UTF-16 可读串（2026-08-28 · 新模态）

> 动机：部分工程把 SPI 表或时钟以 **十六进制/十进制 ASCII**（甚至 UTF-16LE）嵌进 BRAM 供调试。此前 §3/§5b 只做二进制 BE/LE。  
> 镜像：`assets/firmware/20230825_s2056.bin`（6 692 588 B）。一次性 `count`；**不**新增常驻扫描脚本。

| 类 | 靶标（示例） | exact | UTF-16LE | 判读 |
|----|--------------|-------|----------|------|
| CDCE hex | `683C0350` / `683C0340` / `05FC270A` / `0FFC270A` / `83800002` / `E9800004` | **0** | **0** | 无可读 hex ROM |
| 器件名 | `ADS62P49` / `DAC3283` / `CDCE72010` / `fmc150` / `FT600` | **0** | **0** | 无明文器件字符串 |
| 频率 ASCII | `245.76` / `491.52` / `122.88` / `163.84` | **0** | **0** | 无调试用频率字面量 |
| 频率十进制 | `245760000` / `491520000` / `122880000` / `163840000` | **0** | — | 同上 |

**结论**：不支持「位流内嵌可读 SPI/频率调试表」；与 §3/§5b 二进制阴性一致。**仍不升 P1.3/P1.4**（无字符串 ≠ 无该频率/无 SPI）。
