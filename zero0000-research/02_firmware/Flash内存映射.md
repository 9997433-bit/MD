# Flash 内存映射

## 器件
| 项 | 值 | 等级 |
|----|----|------|
| 芯片 | Spansion/Infineon **S25FL128S / FL128SAIF00**（U21） | ✅ |
| 容量 | 128 Mbit = **16 MB** | ✅ |
| 镜像文件 | `20230825_s2056.mcs` | ✅ |
| 有效载荷 | **6,692,572 B**（≈6.38 MB） | ✅ |

## 地址布局

```
0x0000_0000  ┌─────────────────────────────┐
             │ FF 填充 (32 B)               │
0x0000_0020  ├─────────────────────────────┤
             │ Boot: 000000BB 11220044      │
0x0000_0030  ├─────────────────────────────┤
             │ SYNC AA995566 + 配置命令流    │
             │ IDCODE=0x0364C093 (K160T)    │
             │ … 未压缩 bitstream …         │
0x0066_1EDC  ├─────────────────────────────┤
             │ （镜像结束）                  │
             │ 剩余 ≈9.6 MB 未用/0xFF        │
0x0100_0000  └─────────────────────────────┘  (16MB 终点)
```

| 区段 | 范围 | 内容 |
|------|------|------|
| Header | 0x00–0x2F | 宽度检测 + dummy |
| Bitstream | 0x30–0x661EDB | 单用户镜像，无 golden |
| Free | 0x661EDC–0xFFFFFF | 未占用 |

## 含义
- **无 multiboot**：变砖恢复只能靠 JTAG 重写 Flash（见 SOP）
- 烧录选 *Configuration File Only* 即可，不必全片擦 16MB
