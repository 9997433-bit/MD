# 位流逆向：能推出什么 / 推不出什么（s2056）

> 日期：2026-08-28  
> 范围：仅 `20230825_s2056` / XC7K160T。回答「如何根据二进制反向推出」。  
> 对象：`assets/firmware/20230825_s2056.mcs`（→ `.bin`）。

---

## 0. 一句话

对综合后的 7 系列配置位流，**能**可靠推出器件身份、加密否、自举方式、占用/BRAM 粗态、以及「有无明文常量表」；**不能**直接读出采样率、插值倍数、SPI 实写值或「板内是否有 NCO/FIR/FFT」。后一类必须走 **G2 钟/SPI → G3 激励**（见研究计划）。

---

## 1. 反推阶梯（按可核验强度）

```text
① 容器/包解析     → 身份、加密、Master-SPI、完整器件帧数
② 明文/常量扫描   → 有无 SPI 初值表、频率字面量、IP/核字符串
③ BRAM/帧密度     → 有无大规模已初始化 ROM / 软核镜像
④ 同构先验对照    → 候选钟计划 A/B/C + SPI 靶标（非本板实测）
⑤ 公开 frame map  → 精确网表/BRAM 边界（本器件路径已关闭）
⑥ 电气实测 G2     → 样钟 Hz + SPI 寄存器（P1.3/P1.4）
⑦ 激励收数 G3/G4  → 缓冲/抽取/NCO/FIR/FFT 判别
```

| 阶 | 脚本 / 文档 | 本板结论 | 可升命题 |
|----|-------------|----------|----------|
| ① | `analyze_bitstream.py` / `位流特征与软核线索.md` | XC7K160T、未加密、单镜像、Master-SPI、53% 非零帧 ✅ | 位流身份；P1.5 仅「FPGA 自举」 |
| ② | `search_spi_constants.py`、`search_net_constants.py`、`search_fmc150_mif_rom.py` | Conserviss/E2E/KC705 MIF/FFT 明文 **整表阴性** ✅ | 削弱「明文 ROM 写表」；**不**升 P1.4 |
| ③ | `analyze_bram_frames.py` | BRAM 候选区近空 → 不像大规模 BRAM 软核 🔶 | P2.5 强 🔶 |
| ④ | `G1_FMC150_VC707对照.md`、`decode_cdce_profile.py` | 先验 A/B/C + SPI 靶标表 | 假说层；等级仍 ❓ |

| ⑥⑦ | `g2_inbox` + ingest/apply；G3G4 矩阵 | **未做**（无实测投放） | Must-1/3 阻塞点 |

## 2. 为什么「扫二进制」推不出①采样率 / ②算法名

| 误解 | 事实 |
|------|------|
| 位流里应有 `245760000` 或 `FFT` 字符串 | 综合后通常**无**网表符号；本板 ASCII/UTF-16/频率字面量已扫为阴性（`位流SPI常量搜索.md` §5c） |
| 阴性 = 板内无 FFT | **错**。阴性只排除「明文标签/公开 MIF 整表」；硬 IP 可无字符串 |
| 用 prjxray 还原 LUT 网表即可命名算法 | 公开 DB **无 K160T**；禁止用 K70T tilegrid 外推 |
| 找到 SPI 常量即可定模式 | 本板高辨识度 CDCE 字 **0 命中**；即使命中也只是候选，须 LA 抓包确认实写 |
