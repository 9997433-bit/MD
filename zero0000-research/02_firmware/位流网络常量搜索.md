# 位流网络常量搜索

对展开 mcs 镜像做 IPv4/VID 裸搜（误报率高）。

| 常量 | 出现次数 |
|------|----------|
| `192.168.0.1` | 0 |
| `192.168.1.1` | 0 |
| `192.168.0.10` | 0 |
| `10.0.0.1` | 62 |
| `255.255.255.0` | 250 |
| FTDI VID `0403` BE | 111 |
| PID `601e` BE | 4 |
| PID `1e60` LE | 0 |

## 结论

无可信固定 IP 明文；裸命中不可单独采信（❓）。与无 lwIP 字符串、偏纯逻辑 MAC 一致（🔶）。
