# 板卡内固件工作流程（s2056 / zero0000）

> 回答：「板上固件上电后怎么跑？」——按时间轴拆成可验收阶段。  
> 范围：仅 `20230825_s2056`。不做 4431。  
> 证据等级：✅ / 🔶 / ❓。虚线步骤 = 假说，须 G2/G3 才能升格。

---

## 0. 一句话

Flash 里是一份 **未加密、单镜像、Master-SPI 自举的 XC7K160T 配置位流**（✅）。上电后 FPGA 先把自己配置成「定制数据通路逻辑」（🔶，非软核主导），再（可能）去配前端三片并开始采/放数；主机经 USB3(FT600) 和/或 千兆网 交互——**协议与算法块尚未实测**（❓）。


## 2. 分阶段说明

### A. 电源与时钟源就绪 —— ❓（需实物）

- 输入经 EMI/buck/LDO 树（见 `电源树.md`）。  
- X1=491.52 MHz VCXO、X2≈100 MHz、X3≈200 MHz 在板（🔶 丝印）。  
- **未上电测过**任何轨或钟。

### B. FPGA 配置自举 —— ✅

| 事实 | 证据 |
|------|------|
| 器件 XC7K160T | 丝印 + 位流 IDCODE `0x0364C093` |
| 未加密、单镜像 | CTL0 DEC=0；WBSTAR=0；单 SYNC |
| Master-SPI 从 Flash 加载 | 位流命令含 `BSPI_READ`；U21=`FL128SAIF00` |
| 配置体积 | FDRI 16 560 帧，与 K160T 全阵列一致 |

配置完成后，fabric 进入用户逻辑；**无** MicroBlaze/PicoBlaze 明文，BRAM 初值稀少 → **倾向纯 RTL 通路**（🔶，`位流BRAM帧分析.md`）。

### C. 时钟芯片工作 —— ❓（模式）/ 🔶（先验频率）

CDCE72010 可：

1. **仅 EEPROM 自举**（上电无 SPI 写仍出钟）；  
2. **FPGA SPI 重写**全表或补丁；  
3. 主机事后经 FPGA 转发 SPI。

静态无法裁决（P1.5）。频率先验：÷2→ADC 245.76、÷1→DAC 491.52（R6/R8）。G2-2 测脚 + G2-3 嗅探 SPI 才能定。

### D. ADC/DAC 寄存器配置 —— ❓

- 器件接口族：ADC 须 DDR LVDS（高采样率）；DAC 固定 8-bit LVDS+FRAME（✅ datasheet）。  
- 本板是否写出 0x41/插值等位：**未知**；位流无明文写表（✅ 阴性扫描）。  
- 抓包靶标与译码：`FMC150_SPI靶标检查表.md` + `decode_spi_capture.py`。

### E. 链路校准（假说 H5）—— ❓

公开 FMC150 类设计常：开 ramp → 调 IDELAY/bitslip → 关测试图样。本板有无此步，看 G2 SPI 是否出现 0x62/0x75 非零写。

### F. 稳态数据通路 —— 分块等级

| 步骤 | 等级 | 说明 |
|------|------|------|
| 模拟进/出 + 变压器/DAC 滤波 | 🔶 | 照片 |
| LVDS 边沿在跑 | ❓ | 需示波/ILA |
| 深缓冲用 DDR3 | 🔶 | 512 MB + 带宽预算 |
| 抽取 / NCO / FIR / 板内 FFT | ❓ | 假说 H2–H4；禁点名 |
| 成帧 → FT600 / ETH | ❓ | 硬件在板，协议未知 |
| 软核调度命令 | 🔶 倾向无 | BRAM/字符串阴性 |

详见 `FPGA数据通路假说框图.md`。

## 3. 与主机的关系（运行期）

```text
  PC ──USB3── FT600Q ──16-bit FIFO── FPGA 用户逻辑
  PC ──GbE─── RTL8211FI ──RGMII──── FPGA（软 MAC？）❓
  PC ──JTAG── 配置/调试（非业务主路径）
  （可选）RS-232 调试口 via U33 🔶
```

- 作者公开仓 **无** 上位机（R9）。  
- 命令语义（采/停/触发/下发波形）= P2.6 ❓ → G3 抓包。

## 4. 三种「配置归属」裁决实验（P1.5，G2）

| 实验 | 若观察到 | 推断 |
|------|----------|------|
| 不插主机，仅上电，LA 看 SPI | 有固定节拍写序列 | 位流内 SPI 主控（H6） |
| 同上，完全无 SPI，但钟已锁定 | EEPROM 自举为主 | 读 Reg 比对 SCAA090/E2E |
| 接主机后出现第二波 SPI | 主机（经 FPGA）参与配置 | 记协议 |
