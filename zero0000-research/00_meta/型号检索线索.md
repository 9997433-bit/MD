# 型号检索线索(WebSearch 溯源)

> 目的:用公开网络信息为 s2056 / H8.2.3 板卡寻找商用产品型号或设计来源线索。
> 检索日期:2026-08-28。证据分级:✅ 确证 / 🔶 较可信(单源或强推断) / ❓ 存疑待核。
> 结论先行:**未找到与 "s2056" 或 "H8.2.3" 对应的公开商用型号;但板卡模拟前端与时钟树被确证源自 4DSP/Abaco FMC150 参考设计**,整板大概率为国内定制/小批量设计。

## 1. 核心发现:模拟前端 = 4DSP/Abaco FMC150 信号链 ✅

本板 BOM 中 **ADS62P49(双通道 14bit 250Msps ADC)+ DAC3283(双通道 16bit 800Msps DAC)+ CDCE72010(时钟同步/抖动清除)** 三芯片组合,与 4DSP(后被 Abaco Systems 收购)的 **FMC150** FMC 子卡完全一致:

| 对比项 | FMC150(官方资料) | 本板(照片/BOM) | 一致性 |
|---|---|---|---|
| ADC | TI ADS62P49 双通道 14bit 250Msps | U1 疑似 ADS62P49(丝印 AZ6ZP49*) | ✅ |
| DAC | TI DAC3283 双通道 16bit 800Msps | U3 DAC3283I | ✅ |
| 时钟芯片 | TI CDCE72010 | U27 CDCE72010 | ✅ |
| 板载 VCXO | **491.52 MHz** LVPECL(Epson-Toyocom TCO-2111 同款频点) | X1 = **491.520 MHz**(HCI AE) | ✅ |
| 参考时钟 | **100 MHz**(LVPECL,外部参考可选) | Y2 = **100 MHz**(CCPD33CB) | ✅ |
| 典型采样时钟 | ADC 245.76 MHz / DAC 491.52 MHz | 待固件解析核对 | ❓ |

\* TI 官方 ADS62P49 datasheet 封装标印(top marking)即为 **AZ62P49**,与照片丝印 "AZ6ZP49" 的争议可就此闭环——**丝印识读应修正为 AZ62P49,即 ADS62P49 本尊**。此项可将 BOM 中 U1 从 ❓ 升级为 🔶(建议在 `BOM_证据分级.md` 同步)。

证据来源:
- FMC150 产品页(Dedicated Systems):"based on TI's ADS62P49 … and TI's DAC3283 … CDCE72010 clock synchronizer" — <https://dedicatedsystems.com.au/products/fmc150/>
- TI 官网 ABACO-3P-FMC150FPGA 条目 — <https://www.ti.com/product/ADS62P49>
- 4DSP FMC150 用户手册:内部采样时钟 "LVPECL 491.52 MHz",ADC 245.76 MHz,DAC 491.52 MHz — <https://all-guidesbox.com/manual/1289630/4dsp-fmc150-operation-user-s-manual-18.html>
- TI E2E 论坛两帖确认 FMC150 = 100 MHz 参考 + 491.52 MHz VCXO + CDCE72010,并给出可锁定的寄存器组(可直接用于后续固件比对/实测):
  - <https://e2e.ti.com/support/clock-timing-group/clock-and-timing/f/clock-timing-forum/463921/cdce72010-pll-fails-to-lock-on-fmc150-board>
  - <https://e2e.ti.com/support/clock-timing-group/clock-and-timing/f/clock-timing-forum/510180/cdce72010-not-locking>
- TI 应用笔记 SCAA091 记载 491.52 MHz LVPECL VCXO(TCO-2111)为 CDCE72010 官方评估配置 — <https://www.ti.com/jp/lit/an/scaa091/scaa091.pdf>
- ADS62P49 datasheet(Rev. B)器件标印表:ADS62P49 → **AZ62P49** — <https://www.ti.com/lit/ds/symlink/ads62p49.pdf>

推论(🔶):本板设计者直接复用了 FMC150 的模拟/时钟参考设计(原理图级移植),再叠加自研数字侧(K7 + FT600 + RTL8211 + DDR3)。国内确有工程师按此芯片组自制板卡的公开记录(微波EDA网调试帖,491.52 MHz VCXO + 100 MHz 参考 + ADS62P49 + DAC3283)— <http://ee.mweda.com/ask/352265.html>。

## 2. Kintex-7 与 FMC150 的"官配"关系 ✅

- Xilinx 官方 **Kintex-7 FPGA DSP Kit** = KC705(XC7K325T)+ 4DSP FMC150,Avnet 型号 AES-K7DSP-325T-G — <https://www.bdtic.com/download/Xilinx/Kintex-7-DSP-Kit-Product-Brief.pdf>、<https://uk.rs-online.com/p/fpga-development-tools/7686080>
- 含义:K7 + FMC150 是有大量公开参考代码的经典组合(时序约束、CDCE72010/ADS62P49/DAC3283 SPI 配置均有现成工程可抄),把二者合并为单板是低风险的定制路线。这解释了本板"单板集成 FMC150 前端"的设计动机(🔶 推断)。

## 4. "H8.2.3" 直查结果:无 PCB 版本命中 ❓

"H8.2.3" 在电子/PCB 语境无任何命中(命中项为焊接规范 AWS D1.1 附录 H、暖通手册、水厂文档等,均无关)。结论(🔶):**H8.2.3 为板卡丝印上的内部硬件版本号**(H = Hardware,v8.2.3 或第 8 版第 2.3 修订),配合丝印 "C11"、"2026/06" 属同一套内部版控体系,无法通过公网反查厂商。

## 6. 综合判断

1. **整板身份(🔶)**:国内定制/小批量的"USB3.0 + 千兆网双通道中频采集回放卡",模拟前端与时钟树照搬 4DSP FMC150 参考设计,数字侧(XC7K160T-FFG676、FT600、RTL8211FI、DDR3×2、S25FL128)自研。s2056 为内部代号,H8.2.3 为内部硬件版本。
2. **非成品仪器改板(❓)**:未发现对应整机(示波器/信号源/SDR)拆机记录;不排除是某科研院所或公司内部课题板。
3. **时钟树预期(🔶,待固件核验)**:100 MHz 参考 → CDCE72010 锁 491.52 MHz VCXO → ADC 245.76 Msps、DAC 491.52 Msps(FMC150 默认频率计划);X3 200 MHz 供 FPGA/DDR3,Y2 100 MHz 兼作系统时钟。

## 7. 对其他文档的修订建议

- `BOM_证据分级.md` U1:丝印 "AZ6ZP49" 应为 **AZ62P49 = ADS62P49 官方标印**,争议项 2 可闭环,升级 🔶。
