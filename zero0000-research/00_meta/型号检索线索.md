## 二、s2056：无产品命中，判定为内部编号

多轮检索（中英文、含 `.mcs` 文件名）均未命中任何 FPGA/采集卡产品。命中的全部是同名干扰项：

- Inchange/Toshiba **S2056 NPN 功率三极管**（电视行输出管，1500V）——与本板无关（[dtsheet](https://dtsheet.com/doc/575786/isc-s2056)）；
- **Tyan Tomcat i810e S2056** 上古主板——无关；
- **SMPTE ST 2056-2011** 广播标准——无关；
- **Labnet S2056A** 振荡培养箱——无关。

`Montyzhang/zero0000` 仓库本身也未被公开索引关联到任何板卡型号。

**判定（🔶）**：s2056 更可能是**厂商内部项目号/订单号/序列号**，配合固件名 `20230825_s2056.mcs` 的"日期_编号"格式，符合小批量定制板固件的常见命名法。Q02 建议按此方向收口：溯源只能走供货方/采购渠道，公开检索已穷尽。

## 三、H8.2.3：无命中，判定为内部硬件版本号

检索"H8.2.3 硬件版本/PCB"仅返回各类文档的章节编号噪声（焊接规范、船机手册等），无任何电子产品版本命中。

**判定（🔶）**：`H8.2.3` 符合国内硬件团队常用的 **H<主版本>.<子版本>.<修订>**（H=Hardware）版本命名习惯，与固件名中的日期 20230825 为"硬件版本 + 固件日期"双轨编号的可能性最大。Q03（H8.2.3 与 20230825_s2056 是否对应）无法由公开信息裁决，需实物丝印或供货方确认。

## 四、模拟前端血统：确认指向 4DSP/Abaco FMC150 原版

1. **AZ62P49 = ADS62P49 确认（✅）**：TI 官方 datasheet（SLAS635，Rev. B）订购信息表明确列出 ADS62P49IRGCT/R 的 package marking 为 **AZ62P49**（[ti.com PDF](https://www.ti.com/lit/ds/symlink/ads62p49.pdf)）。Q09 的丝印判读由此升级为一手证据闭环。
2. **TI 官方推荐板卡（✅）**：TI 产品页将 ADS62P49 关联到 Abaco **FMC104 / FMC108 / FMC150** 三款 FMC 夹层卡；其中 FMC150 = ADS62P49 + DAC3283 + （时钟综合）双通道 AD/DA 子卡，与本板三件套逐芯片一致（[ti.com.cn 工具页](https://www.ti.com.cn/tool/cn/ABACO-3P-FMC150FPGA)）。
3. **TI TSW4200 演示套件（✅ 旁证）**：TI 官方 TSW4200 套件即 DAC3283 + ADS62P49 + CDCE72010 组合（CDCE72010 输出 245.76 MHz 给 ADC），说明该三件套是 TI 官方参考信号链，与本板 491.52/245.76 MHz 时钟树推断互洽（[SLWU071C](https://www.ti.com/lit/ug/slwu071c/slwu071c.pdf)）。
4. **排除国产太速"FMC150"（✅ 排除证据）**：太速科技（orihard.com）售卖的同名"FMC150"子卡实为 **ADS62P49 + AD9122（DAC）+ AD9516（时钟）**（[产品页](http://www.orihard.com/product/150.htm)），DAC 与时钟芯片均与本板不符。因此本板模拟前端抄的是 **4DSP/Abaco 原版 FMC150**（DAC3283+CDCE72010），而非国内流通的太速改版。这缩小了原理图/参考代码的溯源范围：固件侧应优先比对 4DSP FMC150 官方参考设计的信号命名。

## 五、数字侧血统：K7+FT600 有同型公开先例，但整板仍属定制

1. **HuMANDATA EDX-009（✅）**：日本 HuMANDATA 的 Kintex-7 USB3.0 FPGA 板，FT600 做用户数据通道 + FT232H 做配置，且有 **EDX-009-160T = XC7K160T-1FBG484C** 选配，与本板 FPGA 型号一致（[产品页](https://www2.hdl.co.jp/en/ft600-series-m/edx-009-m1.html)）。证明"K7+FT600"组合有成熟公开先例，本板 USB 侧无需特殊 IP。
2. **国内 FT600/FT601 生态（✅ 旁证）**：米联客（uisrc）、电子发烧友等社区有大量 FT600/601Q + FPGA 的 245 Synchronous FIFO 模式开源工程，实测 340–380 MB/s；FT600Q 为 16-bit FIFO、上限 200 MB/s。本板 USB 通道逆向可直接套用该模式时序。
3. **XC7K160T 国产采集卡对照（✅ 排除）**：太速 230 号 PCIe 采集卡用 XC7K160T + AD9653，走 PCIe 而非 USB；Numato/Sinelec Nereid（K7 160T）走 PCIe+FMC。均与本板形态不符。
4. **四合一整板（🔶）**：截至本轮，公开市场（Abaco/Avnet/HuMANDATA/Numato/太速/坤驰/淘宝/立创）均无 K7 + FT600 + ADS62P49 + DAC3283 + CDCE72010 的一体成品。维持初稿判断：本板为 **FMC150 参考设计 + FT600 USB3 通道 + 千兆网** 的国内定制整合板。
