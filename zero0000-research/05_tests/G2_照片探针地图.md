## 3. SPI / LVDS 飞线优先焊盘（G2-3 / G2-5）

> 规则：禁止带电直戳 QFN 脚；先断电蜂鸣「串阻一端 ↔ 芯片脚」。

### 3.1 首选：五连串阻 **R83 / R88 / R89 / R105 / R106**

- 裁剪：`g2_adc_series_R_cluster.jpg`（图27 区域放大）  
- 布局：五只贴片电阻一字排开，走线朝向 FPGA↔时钟/转换器区  
- 假说（❓）：很可能是 **共享 SPI（SCLK/MOSI）+ 片选/回读/LOCK 之一组**——数量与「共享时钟数据 + 多片选」相容，但**必须蜂鸣到 U1 SEN / U3 SDENB / U27 SPI_LE·SPI_CLK·SPI_MOSI** 才能定名  
- U27 SPI 脚（datasheet ✅）：SPI_MOSI=44、SPI_LE=45、SPI_CLK=46、SPI_MISO=15 —— 蜂鸣时以脚位为金标准  

### 3.2 ADC 旁差分串阻簇 **R43–R48**

- 同裁剪可见 `R44/R46/R48` 与 `R43/R45/R47` 成对  
- 假说（❓）：ADS62P49 LVDS 数据/时钟串阻 → **G2-5** 探随路 CLK 时优先这些焊盘外侧，勿探 U1 脚  

### 3.3 地/参考

- **TP1**（图26 FPGA 南侧金测点，`g2_crop_fpga_south_tp.jpg`）→ 示波器/LA 地优先接此或 SMA 外壳  

### 3.4 LA 通道建议（定名后）

沿用 `G2_仪器与探针清单.md` §3.1；飞线焊在**已蜂鸣确认**的串阻外侧，再上电抓「仅上电、无主机」。

## 5. 有板最短操作序（接 Day-1）

1. 对照本文件拍照确认 SW5/SW42 仍与 §4 一致（有变先记差异）  
2. 断电：蜂鸣 R83/R88/R89/R105/R106 → U1/U3/U27 SPI 脚，填「电阻↔网名」表  
3. 焊 LA 飞线 → 限流上电 → 按 `G2_当日执行包.md` 出 JSON  
4. 钟：C2/C3 至少一条落入 122.88/245.76/491.52 族 → 冲 P1.3
