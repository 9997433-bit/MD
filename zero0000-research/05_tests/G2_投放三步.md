# G2 投放三步（解锁 Must）

> 最短路径：把**实测**放进 inbox → `ingest` 出报告 → `apply_g0_backfill.py --apply` 回填 G0。  
> 详版：`G2_资源门禁_用户动作.md`、`G2_当日执行包.md`、`G2_照片探针地图.md`。

---

## 1. 测并导出

| 要什么 | 最少要求 |
|--------|----------|
| 钟 | 示波器测 **C2（ADC CLKP）或 C3（DAC DACCLK）** → Hz 整数；主先验 **A/B**（245.76↔491.52/245.76）；**计划 C**（RHINO）：ADC **61.44** / DACCLK **245.76**；旁支 122.88 / **163.84** / **40.96** / **81.92**（R5b/R13 LDV）亦属族。SPI 见 ADC **0x20 LOW SPEED**：C2≤80 MSPS 时期望 =1，否则 =0（脚本交叉核验） |
| SPI | LA 挂 SCLK/MOSI + 三片 CS（飞线优先 R83/R88/R89/R105/R106）；**回读另挂独立 SDO**（R11d：勿把 MOSI 当双向）；建议**仅上电无主机** ≥5 s CSV |

拨位基线：SW5=OFF/OFF；SW42 仅位5 ON。先 Day-1 备份。

---

## 2. 投放到仓库根 inbox（不要放 examples/）

路径：`zero0000-research/05_tests/g2_inbox/`

| 文件名 | 内容 |
|--------|------|
| `g2_clocks.json` | 自 `g2_clocks.template.json` 复制；至少 C2 或 C3 的 `hz` **非 null**；或用 `mk_g2_clocks.py --c2 … --c3 … --confirm-measured`；或示波器截图经 `ocr_scope_hz.py`（须人眼核对） |
| `spi_capture.csv` | LA 导出；列名默认或 Saleae 别名均可 |
| `scope_*.jpg`（可选） | 示波器频率读数照片 → `ocr_scope_hz.py` |

禁止：猜测 Hz；把 `examples/*.csv` 改名冒充实测。  
**可以**把实测文件 `git add` 进 `g2_inbox/` 并推送到本 PR（云端 Agent 会拾取）。

---

## 3. 跑 ingest → 复核 → apply

```bash
cd zero0000-research
python3 scripts/ingest_g2_inbox.py
python3 scripts/apply_g0_backfill.py          # dry-run
python3 scripts/apply_g0_backfill.py --apply  # 写 G0 + G2 记录 + 刷新 Must 审计
# 若 SPI 为仅上电无主机：再加 --power-on-only
```

产出：`G2_inbox_infer_report.md` + `G2_G0回填提案.md`（含 sha256）→ apply 后更新 `G0_命题基线证据表.md` 与 `G2_时钟与SPI记录.md`。

空 inbox / 全 null 钟 → exit 2（当前云环境即此状态）。  
单侧测得 C2 或 C3 且落入族 → 脚本建议 P1.3 **强 🔶**（双侧齐才 ✅）——此等级可翻 Must-1。
