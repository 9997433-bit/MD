# G2 当日执行包（测点 → JSON → 命题回填）

> 在 Day-1 完成后使用。产出可直接喂给 `g2_mode_infer.py`，并粘贴进 `G2_时钟与SPI记录.md`。  
> 探点照片锚点：`G2_照片探针地图.md`（飞线优先 R83/R88/R89/R105/R106；拨位基线 SW5=OFF/OFF）。

---

## 1. 时钟 JSON 模板

保存为 `g2_clocks.json`：

```json
[
  {"id": "C1", "hz": null, "note": "X1 VCXO"},
  {"id": "C2", "hz": null, "note": "ADC CLKP"},
  {"id": "C3", "hz": null, "note": "DAC DACCLK"},
  {"id": "C6", "hz": null, "note": "DAC DATACLK"},
  {"id": "C7a", "hz": null, "note": "X2 100M"},
  {"id": "C7b", "hz": null, "note": "X3 200M"}
]
```

填写实测 Hz（如 `245760000`）后：

```bash
python3 scripts/g2_mode_infer.py --clocks g2_clocks.json
```

---

## 2. SPI CSV → 译码 JSON

```bash
python3 scripts/decode_spi_capture.py capture.csv \
  --sclk SCLK --mosi MOSI --cs-adc SEN --cs-dac SDENB --cs-cdce SPI_LE \
  --json g2_spi_decode.json

python3 scripts/g2_mode_infer.py --clocks g2_clocks.json --spi g2_spi_decode.json
```

把打印的 `P1.3_suggested` / `P1.4_suggested` / `P1.5_suggested` 与 H8 三态 **人工复核**后写入：

- `05_tests/G2_时钟与SPI记录.md`
- `06_docs/G0_命题基线证据表.md`（改等级须附原始文件哈希）

---

## 3. 最小合格（G2 Gate）

- [ ] C2 或 C3 至少一条测得并落入 122.88/245.76/491.52 族 → 冲 P1.3 ✅  
- [ ] checklist 出现 A2（0x41 LVDS）或 D1（CONFIG1）或等价强靶标 → 冲 P1.4 ✅  
- [ ] 「仅上电」SPI 有/无 记入 P1.5  

未达标不得开 G3 算法定性。
