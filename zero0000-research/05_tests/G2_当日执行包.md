## 0. 十分钟填空单（给现场）

拨位：SW5=OFF/OFF；SW42 仅位5 ON。先 Day-1 备份。

| 项 | 填这里（整数 Hz 或科学计数） | 探点提示 |
|----|------------------------------|----------|
| C2 ADC CLKP | _______________ | U1 旁；先验 **A/B** 245.76e6 或 **C** 61.44e6；旁支 122.88/163.84/**40.96**/**81.92** |
| C3 DAC DACCLK | _______________ | U3 旁；先验 **A** 491.52e6 或 **B/C** 245.76e6（±1%） |
| C6 DATACLK（可选） | _______________ | FPGA→DAC；B 下常≈122.88e6 |
| SPI CSV 文件名 | _______________ | SCLK/MOSI+三 CS；**回读独立 SDO**（勿用 MOSI） |
| 示波器截图（可选） | _______________ | 频率读数清晰；可 `ocr_scope_hz.py` 辅助 |
| 仅上电无主机？ | 是 / 否 | ≥5 s；是→P1.5 可冲 ✅ |

填完后任选：

```bash
cd zero0000-research
python3 scripts/mk_g2_clocks.py --c2 <C2> --c3 <C3> --confirm-measured
# 把 LA 导出存为 05_tests/g2_inbox/spi_capture.csv
python3 scripts/ingest_g2_inbox.py
python3 scripts/apply_g0_backfill.py --apply   # 仅上电 SPI 再加 --power-on-only
```

或把本表数字发回对话并说「已投放」。

## 3. 最小合格（G2 Gate）

- [ ] C2 或 C3 至少一条测得并落入 40.96/61.44/81.92/122.88/163.84/245.76/491.52 族 → P1.3 **强 🔶** 或 ✅  
- [ ] checklist 出现 A2（0x41 LVDS）或 D1（CONFIG1）或 VERSION31 或 Conserviss/RHINO 剖面 → 冲 P1.4  
- [ ] **交叉**：若 C2≤80 MSPS，SPI 应见 ADC **0x20 LOW SPEED=1**；若 C2>80 MSPS，应见 **=0**（`g2_mode_infer` 自动核）  
- [ ] 「仅上电」SPI 有/无 记入 P1.5  

未达标不得开 G3 算法定性。
