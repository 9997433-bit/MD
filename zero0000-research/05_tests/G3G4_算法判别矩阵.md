> 性质：**方案 + 空白矩阵**（无板上主动实验结果）。

## 1. 打分规则

| 分 | 含义 |
|----|------|
| 0 | 无证据 / 未做实验 |
| 1 | 弱：单一现象相容，有合理解释空间 |
| 2 | 强：可复现且直接满足命题成功标准 |

每条假设必须另标：**保留 / 排除 / 未决**。排除必须写清证伪现象。

| Conserviss CDCE Reg0/RegA 明文或 Hamming≤2 近邻 ROM | 同文档 §5b：Reg0/RegA ham≤2 =0；多 Reg 共窗簇=0 | 2026-08-28 |

### 4.1b 归因陷阱排除（datasheet+BOM · 不需板）

> Must「哪些算法不像」的一部分：排除**错误归因句式**，不等于排除「FPGA 内可能另有 DDC/FIR」。

| 已排除的错误归因 | 证伪依据 | 日期 |
|------------------|----------|------|
| 仅凭 DAC SMA 见插值镜像/滚降 ⇒ **FPGA 内 FIR** | DAC3283 **片内** 1x/2x/4x 插值 FIR（`信号链` §1.2 ✅；SPI CONFIG1 fir0/fir1） | 2026-08-28 |
| 仅凭 DAC SMA 见 Fs/2、±Fs/4 搬移 ⇒ **FPGA 内 NCO** | DAC3283 **片内** 粗混频器（CONFIG0 mixer_func；同 §1.2 ✅） | 2026-08-28 |
| 仅凭 ADC 上传样率 ≪ 250 MSPS ⇒ **板上必有 FPGA 抽取** | 带宽预算下「DDR3 段采 + 主机抽稀」亦可解释（G0 P2.1/P2.2）；须 G3 区分 | 2026-08-28 |
| 把 DAC 片内能力写成「本板 FPGA 已启用」 | `算法线索_资料对照.md` §1 红线；启用与否须 G2 SPI | 2026-08-28 |
| 「FMC150 血统 ⇒ 板内必有 FFT/DDC」 | Conserviss VC707 IP 为时域 AXI 流、谱在主机（`G1_FMC150_VC707对照.md`）；**不排除本板另做** | 2026-08-28 |
| 经**单路 GbE** 做「连续满速双通道原始码流」主机架构 | 满速 ≈0.9 GB/s ≫ GbE≈118 MB/s（G0 P2.1；R11 Conserviss 7.86 Gbit/s 同量级） | 2026-08-28 |
| 在钟**计划 B**（ADC245.76 / DAC 数据率122.88）下主张「**无抽取** ADC→DAC 数字直通」 | Conserviss `limitations`：率比 2:1，直通须抽取（`G1` §7）；**仅当本板 G2 确认为 B 时对本板生效** | 2026-08-28 |
| 在钟**计划 C**（ADC61.44 / DACCLK245.76）下照搬 Conserviss「ADC:DAC **数据率** 2:1 ⇒ 必抽」句式 | R5c：样钟比 1:4，与计划 B 数据率故事不同；插值/DATACLK 须另测 C6；**勿**把 B 的 2:1 直通结论直接套到 C | 2026-08-28 |
| 以 RHINO_CALF 开源 **DDC/DUC** 直接断言本板 FPGA 算法 | R5d：开源仓有 NCO；本板位流无高辨识度 NCO 字簇 → **血统 ≠ 本板实现**（§4.2） | 2026-08-28 |

**G3 分辨句**（有板后）：SPI 读到 fir/mixer 位 + 测 C3/C6（DACCLK/DATACLK）→ 片内插值；再改 Fin 看**上传**是否平移 → 才谈 FPGA DDC（矩阵 H-DDC）。  
G2 若 H8=计划 C：先按 61.44 样钟估主机样率比，再谈抽取（P2.2）；并优先跑 H-DDC（R5d）。

### 4.2 算法模块 / 通路形态排除（静态可写部分）

> Must-2：「明确哪些算法**不像**」。下表排除的是**可证伪的实现形态/通路**；**不**排除「板内可能存在无符号硬 IP FFT/DDC/FIR」——后者仍须 G3/G4。  
> 禁止把「位流无 FFT 字符串」写成「板上无 FFT」（G0 §3.4）。

| 已排除项 | 证伪实验与现象 | 日期 |
|----------|----------------|------|
| 以**大规模 BRAM 驻留软核程序镜像**承载板内 FFT/FIR/NCO | `位流BRAM帧分析.md`：候选区非零 ≈5.5 KB → 该**软件 DSP 形态**不像（🔶 强排除） | 2026-08-28 |
| 以**单路 GbE 连续满速双通道原始样**为唯一上传算法 | 满速 ≈0.9 GB/s ≫ GbE≈118 MB/s（G0 P2.1；R11）→ 该上传算法不像（✅） | 2026-08-28 |
| 在钟**计划 B**成立时，以**无抽取 ADC→DAC 数字直通**为唯一通路算法 | Conserviss：ADC:DAC 数据率 2:1，直通须抽取（`G1` §6）；**条件排除**，须 G2 确认本板为 B | 2026-08-28 |
| 在钟**计划 C**成立时，以 Conserviss **2:1 数据率**句式直接断言「必有/必无 FPGA 抽取」 | R5c 样钟 61.44↔245.76（1:4）≠ B 的数据率契约；抽取判定须对照主机样率与 C6（**条件排除错误套用**） | 2026-08-28 |
| 以**位流内嵌明文 ASCII 标签**的 Xilinx FFT/FIR/DDS/CIC/`NCO` 为唯一可识别 IP 形态 | `位流特征` §4.1 复扫 0 → **仅排除带符号明文形态**（✅）；同名无符号硬 IP **未**排除 | 2026-08-28 |
| 以「FMC150 血统必含板内 FFT/DDC」为默认算法选型 | Conserviss 参考 = 时域 AXI + 主机谱（R10）→ 该**默认选型**不像；本板另做仍可能 | 2026-08-28 |
| 以「RHINO_CALF 开源含 DDC/DUC」⇒ **本板必有** FPGA NCO/DDC | R5d：该仓 ✅ 有 DDC/DUC+NCO（Fs=61.44）；本板位流 NCO 字噪声/阴性（§5e）→ **禁止血统外推**；仅提高 G3 H-DDC 优先级 | 2026-08-28 |

**仍开放（须 G3/G4 实验行）**：无符号硬 IP FFT/DDC/NCO/FIR 本体；形态 A/B/C；H1–H9 支持/证伪；DAC 片内 fir/mixer **是否已启用**（须 SPI）。
