# L5 功能实测方案（无实物可先准备）

## 目标
验证 ADC 或 DAC 至少一个通道真实工作。

## 无实物准备
- [ ] 信号源/示波器/SMA 线需求清单  
- [ ] 对照 `信号链_ADS62P49_DAC3283_CDCE72010.md` 画测试接线图  
- [ ] 定采样率候选：122.88 / 245.76 MSPS（3GPP 族）  
- [ ] 准备数据落盘与简单 FFT/幅度检查脚本  
- [ ] 阅读 `03_architecture/FMC150_SPI靶标检查表.md`（时钟锁定 / ADC DDR / DAC 版本读回）

## 有实物最小路径（二选一）

### 路径 A：ADC
1. 确认 CDCE PLL_LOCK（靶标表 Reg12）与 ADC 0x41 DDR 配置（若可嗅探）  
2. SIG1 注入已知正弦（注意幅度 < ADC 满幅）  
3. 经 USB/ETH 收数  
4. 核对频率/幅度/SNR 量级  

### 路径 B：DAC
1. 可选：读 DAC 0x1F VERSION 确认 SPI 通  
2. 上位机下发波形或板内 DDS  
3. 示波器看 DAC1/DAC2  
4. 核对频率与杂散量级  

### 同步相关（可选）
- CLK_IN 外参考锁定  
- TRIG 触发对齐  

## 判定量级（最低通过线 · 参考 datasheet 典型）

| 路径 | 指标 | 最低通过（量级） |
|------|------|------------------|
| ADC | 注入单音频率误差 | ≤ 1%（相对设定值） |
| ADC | 幅度 | 可见且无削波；满度建议 ≤ −3 dBFS |
| ADC | SNR 量级 | 粗看 ≥ 50 dB（14-bit 链，非实验室极限） |
| DAC | 输出频率 | 示波器读数误差 ≤ 1% |
| DAC | 杂散 | 主峰清晰可辨，无异常满幅振荡 |

细化 FFT 可用 `scripts/l5_fft_check.py`。
