|------|----------|

| `E1736A_GetSensorInfo` | 传感器元数据 |

### 4.4 采集模式（来自 `E1733A_Remote.h` + `Sample.Lin`）

`MEASETUP_TRIGTYPE_CHOOSING` 定义三种触发：

| 值 | 模式 | 说明 |
|----|------|------|
| 0 | Manual | 操作员手动 Record |
| 1 | Encoder | A-Quad-B 编码器脉冲触发 |
| 2 | Auto | CNC 自动到位后采集 |

`Sample.Lin` 示例配置：
- `TrigType=2`（自动）
- `TrigWnd=0.5 mm`（到位窗口）
- `TrigDwell=1 sec`（稳定等待）
- `Cycles=5`（5 个测量循环）
- `Mode=0`（双向）
- `Positions`：11 个非等间距目标位（含随机偏移，符合 ISO 230-2）

### 4.5 环境补偿参数（采集阶段实时）

来自 `Remote.h` 的 `ENVSETUP_*` 与 `English.csv`：

- **空气**：`AirTemp`、`AirPressure`、`RelativeHumidity` → **Wavelength Compensation**
- **材料**：`MatTemp1/2/3` + `ExpCoef`（膨胀系数）→ **Material Compensation / NDE Correction**
- **单位**：Metric / English / SI（C + kPa）
- **更新**：`EnvUpdate` 周期（示例 10 s）；双轴无传感器时可 Manual/Import

物理公式（行业标准，DLL 内部实现，非源码可见）：

\[
L = \frac{\lambda_{\text{air}}(T,P,RH) \cdot N}{2}, \quad \lambda_{\text{air}} = \frac{\lambda_{\text{vac}}}{n_{\text{air}}(T,P,RH)}
\]

| `E1733A_CI_FWDREPEATPOS` / `REVREPEATPOS` | \(R^+\) / \(R^-\) |

### 5.5 斜率算法选择

`ANASETUP_ANASLOPE_CHOOSING`：
- 0 = **Least Squares**（最小二乘）
- 1 = **End Points**（端点法）

### 5.6 平面度专用

`ANASETUP_FLAMETHOD_CHOOSING`：0 = **Moody** 分析法。

### 5.7 原始误差数据接口

`E1733A_CC_READERRORDATA (62)`：按轴号、运行次数、位置索引读取 float 误差值。

## 6. 补偿模块静态分析

### 6.1 补偿表配置参数（`CMPSETUP_*`）

| 参数 | 选项 | 含义 |
|------|------|------|
| `CompSign` (Type) | 0=Correction, 1=Error | 输出补偿量还是误差量 |
| `CompAbs` (Error Sign Convention) | 0=Algebraic, 1=Calibrator | 符号约定 |
| `CompCalc` (Compensation Values) | 0=**Absolute**, 1=**Incremental** | 绝对值 / 增量式 |
| `CompDir` (Direction) | 0=Combined, 1=Forward/Reverse | 单向/双向补偿表 |
| `CompSel` (Target Position) | 0=**Target List**, 1=**Interpolate** | 用实测点 / 等间距插值 |
| `CompStart/End/Intvl` | 数值 | 补偿网格起止与间距 |
| `MachUnit` | 如 `1 um` | CNC 机床单位 |
| `CompZero` | 机床零点参考 | |
| `CompProg` (Download) | 字符串 | 下载程序名（55291A 等） |

`Sample.Lin` 示例：
```
CompCalc=0      → Absolute（绝对补偿）
CompDir=0       → Combined（双向合并）
CompSign=0      → Correction（输出修正量）
CompSel=0       → Target List（按实测目标位）
CompStart=6.711 mm, CompIntvl=174.4209 mm, CompEnd=1750.92 mm
```

### 6.2 补偿量计算逻辑（从头文件 + 示例数据推断）

1. 对每个目标位置 \(P_i\)，计算平均位置偏差 \(\bar{x}_i\)（双向或单向）
2. 补偿值：\(C_i = -\bar{x}_i\)（当 Type=Correction 时）
3. 若 `CompSel=Interpolate`：在 \([Start, End]\) 按 `Interval` 等间距重采样（线性插值）
4. 若 `CompCalc=Incremental`：输出相邻点差值 \(\Delta C_i = C_i - C_{i-1}\)（适配 Fanuc 等增量螺距补偿）
5. 导出格式（`E1733A_CC_SAVE`）：
   - `COMPTABLE_TXT` / `COMPTABLE_CSV` / `COMPTABLE_POS` / `COMPTABLE_RUN`

### 6.3 示例误差数据（`Sample.Lin` 内嵌）

`LinearErr` 字段含 **110 个** 实测误差值（µm），对应 11 点 × 5 循环 × 双向的结构化原始数据，可直接用于复现分析算法。

### 6.4 CNC 下发链路

```
E1733A 补偿表 → 55291A 格式转换 → RS-232 → Fanuc/Siemens 螺距误差参数
```

静态分析未发现 E1733A 直接写 CNC 寄存器的代码；下发依赖外部 `55291A` 工具（未包含在本安装包中）。

## 7. 数据文件格式（Option Description File）

所有 `Sample.*` 文件均为文本格式：

```
<Option Description File - Rev. 1.00a - Keysight E1733A 1.12>
UserSetup
Identify=MeaType,Choosing=0
Identify=Positions,"TextUnit=6.7110,181.1319,... mm"
Identify=LinearErr,"TextUnit=-1.2,-0.5,0.2,... um"
...
<End of Option Description File - Rev. 1.00a>
```

**关键字段类型**：
- `Choosing=N`：枚举选项
- `ItemText=...`：整数/字符串
- `TextUnit=...`：带物理单位的数值
- `Comprise=YYYY...`：多位布尔开关

此格式完整保存了**测量配置 + 原始数据 + 分析设置 + 补偿设置 + 环境历史**，是离线研究算法的最有价值静态资源。

## 8. 远程自动化接口摘要

启动参数：`E1733A.exe /RemoteName=<name>`

通信方式：
```c
SendMessage(hWnd, E1733A_WM_REMOTECOMMAND /*0x0500*/, wParam, lParam);
```

主要命令码：

| Code | 功能 |
|------|------|
| 40 NEW | 新建测量（LINEAR/ANGULAR/...） |
| 53 START | 开始/继续采集 |
| 54 RECORD | 手动记录一点 |
| 55 STOP | 停止 |
| 57 SAVE | 保存（含补偿表 CSV） |
| 62 READERRORDATA | 读误差数据 |
| 66 ANALYSIS | 读分析统计量 |
| 64/65 READ/WRITESETUPVALUE | 读写全部配置项 |

共享内存传递文件名与字符串参数。
