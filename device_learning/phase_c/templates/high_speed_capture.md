# 高速连续采集实验模板

**用途**：在目标高速配置下验证 ADC 到 FPGA、Slave FIFO 和 USB 数据流的连续性，并定位吞吐瓶颈与数据损坏。

**声明**：本模板是待执行的实验清单，不构成性能、稳定性或厂商等价声明。测试通过只说明所记录设备与配置在本次观察窗口内满足判据；任何 `confirmed` 状态变更都需要原始证据和人工审阅。

## 1. 实验关联

| 实验 | 本模板中的作用 |
|------|----------------|
| `EXP-004-PIN-FIFO` | 观察 FIFO 写选通、标志和端点选择是否出现停顿或背压 |
| `EXP-005-PIN-ADC` | 确认 ADC 数据就绪、移位时钟和帧同步在高速模式下稳定 |
| `EXP-008-SINE-IN` | 以已知信号检查高速数据的幅值、频率和连续性 |
| `EXP-009-CLOCK-IFCLK` | 实测接口时钟并计算理论传输上限 |
| `EXP-014-DATA-FRAME` | 验证帧边界、样本打包、序号和短包处理 |

## 2. 安全与准备

- [ ] 确认对设备、驱动和通信数据有合法分析授权
- [ ] 核对高速模式下允许的输入幅度、带宽、阻抗、温度和供电范围
- [ ] 准备带宽足够的信号源、示波器/逻辑分析仪、探头和 USB 抓包工具
- [ ] 禁用主机休眠和 USB 选择性挂起，记录电源方案及 USB 控制器拓扑
- [ ] 确认采集盘剩余容量和持续写入速度高于预计数据率
- [ ] 记录设备序列号、硬件版本、固件/驱动版本、主机 OS 和测试配置
- [ ] 复制 `phase_c/templates/experiment_log_template.json`，为每个关联 EXP 建立日志

## 3. 计算目标与判据

- [ ] 填写通道数：____；每通道采样率：____ Sa/s；每样本有效位数：____
- [ ] 填写 `EXP-014-DATA-FRAME` 得到的存储字节数、帧头和填充开销
- [ ] 计算期望负载率：通道数 × 采样率 × 每样本存储字节数 = ____ B/s
- [ ] 按 `EXP-009-CLOCK-IFCLK` 实测 IFCLK 频率、总线宽度和有效周期占比
- [ ] 记录 USB 端点、最大包长、每次提交大小和并发传输数
- [ ] 预先定义丢帧、重复帧、错序、短包、样本错误和允许停顿的阈值
- [ ] 定义最短连续运行时长和需要保存的完整原始数据量

## 4. 基线采集

- [ ] 向全部启用通道施加处于通带内的已知正弦信号
- [ ] 按 `EXP-008-SINE-IN` 先在低采样率采集基线并保存原始 USB 流
- [ ] 按 `EXP-014-DATA-FRAME` 验证字节序、有符号格式、通道交织和帧边界
- [ ] 计算每通道频率、幅值、直流偏置及噪声，保存分析参数
- [ ] 确认基线无异常后再提高采样率，不以应用界面显示正常代替原始流检查

## 5. 高速阶梯测试

- [ ] 以低、中、目标最高采样率逐级测试，并记录每级的实际配置命令
- [ ] 每一级至少执行三段独立采集，保存开始/停止时间和字节数
- [ ] 按 `EXP-005-PIN-ADC` 捕获 `DRDY` / `FSYNC` / `SCLK`，检查漏脉冲和周期漂移
- [ ] 按 `EXP-004-PIN-FIFO` 捕获 `SLWR`、`FLAG*`、`FIFOADR`、`PKTEND` 与 IFCLK
- [ ] 记录 FIFO 背压、标志翻转、突发长度、空闲间隔和异常停顿
- [ ] 同步记录主机 USB 错误、超时、CPU/内存占用和存储写入速率
- [ ] 达到目标速率后按预定时长连续运行，期间不丢弃错误段

## 6. 完整性分析

- [ ] 统计总包数、总字节数、有效帧数、短包数和不可解析字节数
- [ ] 使用帧序号或可验证模式检测丢帧、重复、错序和拼接错误
- [ ] 若无帧序号，利用已知正弦连续性、帧长度和通道交织联合检测跳变
- [ ] 对照 `EXP-005` 检查 ADC 侧异常是否先于数据错误
- [ ] 对照 `EXP-004` 检查 FIFO 背压或 `FLAG*` 状态是否与数据缺口对应
- [ ] 对照 `EXP-009` 的 IFCLK 和总线宽度，比较实测吞吐与理论上限
- [ ] 按 `EXP-014` 复核高速模式是否改变帧格式、填充或通道顺序
- [ ] 将设备侧、USB 侧和主机存储侧问题分别归类，不把相关性写成因果结论

## 7. 复现与产出

- [ ] 断电重启后重复目标速率测试

- [ ] 保存信号源配置、仪器波形、USB 抓包、应用日志和完整性统计
- [ ] 为每个原始文件计算 SHA-256，并在实验日志中记录路径和哈希
- [ ] 在日志中分别引用 `EXP-004`、`EXP-005`、`EXP-008`、`EXP-009`、`EXP-014`
- [ ] 记录成功条件、失败条件、未覆盖配置及拟升级标识符
- [ ] 保持结论为 `inconclusive`，直到判据、复测和人工复核全部完成
