# 多通道同步采集实验模板

**用途**：验证四个模拟通道的采样同步性、通道顺序与 USB 数据帧中的通道映射。

**声明**：本模板仅指导实机实验与证据记录，不代表实验已经执行。单次观察不能证明所有工作模式均同步，也不会自动把任何标识符升级为 `confirmed`；结论必须保留原始采集物并经人工复核。

## 1. 实验关联

| 实验 | 本模板中的作用 |
|------|----------------|
| `EXP-004-PIN-FIFO` | 对齐 Slave FIFO 写入活动与 USB 数据到达时间 |
| `EXP-005-PIN-ADC` | 测量各 ADC 的 `DRDY` / `SCLK` / `FSYNC` 时序 |
| `EXP-008-SINE-IN` | 向各通道施加已知相位关系的正弦信号 |
| `EXP-009-CLOCK-IFCLK` | 记录 IFCLK 频率并建立统一时间基准 |
| `EXP-014-DATA-FRAME` | 解码样本位宽、字节序、交织顺序与帧边界 |

## 2. 设备与前置条件

- [ ] 确认对设备、驱动和通信数据有合法分析授权
- [ ] 准备至少四路共时钟信号源，或一路信号经等长分配器送入四通道
- [ ] 准备带宽足够的示波器、差分/低电容探头和 USB 抓包环境
- [ ] 核对输入幅度、偏置和终端阻抗均不超过设备额定值
- [ ] 记录设备序列号、硬件版本、固件/驱动版本和主机环境
- [ ] 复制 `phase_c/templates/experiment_log_template.json`，分别为相关 EXP 建立日志

## 3. 建立公共时间基准

- [ ] 按 `EXP-009-CLOCK-IFCLK` 测量 IFCLK，记录频率、占空比、抖动和测点
- [ ] 按 `EXP-005-PIN-ADC` 同时观察 ADC `DRDY` / `FSYNC` 与采样时钟
- [ ] 按 `EXP-004-PIN-FIFO` 同时观察 `SLWR`、`FLAG*`、`FIFOADR` 与 IFCLK
- [ ] 保存示波器原始波形及截图，不只记录人工读数
- [ ] 记录探头传播延迟、通道 deskew 设置和触发源

## 4. 同相信号采集

- [ ] 将同一低失真正弦信号等长分配到全部输入通道
- [ ] 先用示波器在设备输入端确认各路幅度和相位差
- [ ] 按 `EXP-008-SINE-IN` 记录信号频率、幅度、偏置、采样率和采集时长
- [ ] 连续采集至少三段独立数据，每段包含足够周期用于相位拟合
- [ ] 同步保存 USB 原始流、控制传输和应用层导出数据
- [ ] 更换至少一个非整数周期比的输入频率并重复采集，避免固定相位假象

## 5. 通道识别与帧解码

- [ ] 依次仅向单个通道加信号，其余通道接规定终端，建立物理通道到数据槽映射
- [ ] 按 `EXP-014-DATA-FRAME` 判定帧头、样本位宽、字节序、有符号格式和通道交织周期
- [ ] 检查每帧样本数是否恒定，并记录短包、丢帧、重复帧或填充值
- [ ] 将 USB 包时间戳与 `EXP-004-PIN-FIFO` 的写入突发对应
- [ ] 对每个通道计算相邻采样点间隔、跨通道样本索引差和相位差
- [ ] 明确区分固定布线/滤波延迟、整数样本偏移和随时间变化的漂移

## 6. 判定与复测

- [ ] 预先填写允许的通道间偏差阈值：____ ns / ____ samples / ____ degrees
- [ ] 逐通道报告平均偏差、最大偏差、标准差和观察样本数
- [ ] 断电重启设备后重复一次完整测试，检查通道顺序和偏差是否稳定
- [ ] 改变采样率或工作模式后重复测试，不将单一配置外推到其他配置
- [ ] 若结果矛盾，将结论记为 `inconclusive` 并列出下一步排查项

## 7. 产出

- [ ] 保存信号源配置、示波器波形、USB 抓包和解码脚本输出
- [ ] 为每个原始文件计算 SHA-256，并在实验日志中记录路径和哈希
- [ ] 在日志中分别引用 `EXP-004`、`EXP-005`、`EXP-008`、`EXP-009`、`EXP-014`
- [ ] 记录任何拟升级的标识符，但不直接修改其状态
- [ ] 由另一名复核者检查通道映射、时间基准和结论边界
