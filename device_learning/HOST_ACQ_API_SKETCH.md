# 主机采集 API 草案

> 本文仅定义基于现有抓包的候选抽象，不声称复现任何真实厂商 SDK。

## 建议分层

| API | 建议职责 | USB 映射 |
|---|---|---|
| `enumerate()` | 按 USB 描述符列出候选设备 | 枚举/控制传输；不直接使用批量端点 |
| `open(device)` | 打开设备、声明接口 0、建立两组管道 | 命令对 `EP01 OUT / EP81 IN`；数据对 `EP06 OUT / EP84 IN` |
| `command_transact(request)` | 发送一帧并等待对应响应 | 写 `EP01`，读 `EP81`；仅采用抓包观察到的候选帧格式 |
| `start_stream(config)` | 下发候选启动/配置事务并预提交数据读取 | 控制走 `EP01/81`；流数据主要从 `EP84` 读取；`EP06` 的配置或数据作用待证 |
| `read_samples(buffer, timeout)` | 读取原始数据块并返回字节数/状态 | 读 `EP84`；采样解码应置于独立层，当前不假定样本格式 |
| `stop()` | 取消在途读取并下发候选停止事务，释放管道 | 取消 `EP84`；停止控制候选走 `EP01/81`；是否需写 `EP06` 未知 |

## 待确认

- 命令 opcode、启动/停止序列及请求—响应关联规则。
- `EP06/84` 的准确方向职责、帧边界、样本位宽、通道交织、字节序和标定。
- 超时、重试、并发、流控、短包/零长度包及断线恢复语义。
- 设备筛选、固件状态、初始化控制传输及多设备行为。

## 声明

端点映射来自观测资料；API 名称与行为均为设计提案，不是厂商 SDK 接口或兼容性承诺。**目录完整 ≠ 厂商等价 ≠ 掌握运行行为。**
