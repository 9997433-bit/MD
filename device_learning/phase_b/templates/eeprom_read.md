# EEPROM 读取步骤模板（24LC64）

**用途**：记录板载 EEPROM 的读取过程与结果。**本文件为空模板，需在完成实机读取后填写；未读取前，依赖 EEPROM 的 FW-* 项保持 `unknown` / `missing`。**

> 静态位流不含 EEPROM 内容，其字节只能从物理芯片读出，必须有实物设备。

## 0. 芯片信息

- 类型：I²C EEPROM，24LC64（容量 8 KB = 8192 字节）
- 封装：常见为 8 脚 SOIC，位于 USB 控制器附近
- 地址位：A0 / A1 / A2（记录实际接线）
- 供电：按板上实际电压，勿超压

## 1. 安全与前置检查

- [ ] 确认对设备有合法分析授权
- [ ] 断电，避免读取时被板上主控占用 I²C 总线
- [ ] 记录芯片丝印、位号、在板位置（拍照留档）
- [ ] 确认读取器电压与芯片供电匹配

## 2. 接线方式（二选一）

### 方式 A：在板 / 夹具读取（优先）
- [ ] 用测试夹或飞线接出 SDA / SCL / VCC / GND
- [ ] 记录接线对应关系

### 方式 B：离板读取
- [ ] 仅在方式 A 不可行时考虑，注意静电与引脚方向
- [ ] 记录拆焊前后照片

## 3. 读取操作

以通用 I²C 读取工具（如 CH341A 等，按实际填写）为例：

- [ ] 选择器件类型 24LC64
- [ ] 设置 I²C 地址（默认 0x50，按 A0~A2 接线调整）
- [ ] 执行读取，得到 8192 字节
- [ ] 至少读取两次并比对一致，排除接触不良
- [ ] 两次读取比对：`python3 scripts/diff_eeprom.py read1.bin read2.bin`

## 4. 产出与校验

- [ ] 保存镜像：`phase_b/captures/eeprom.bin`
- [ ] 计算哈希：`sha256sum phase_b/captures/eeprom.bin`
- [ ] 将哈希与元数据写入 `manifests/eeprom_meta.json`
- [ ] 确认字节数等于 8192
